# ML class guide (Machine Learning using Python)

Pages: `ml-class-guide.html` (hub) and `ml-guide-<slug>.html` (companion lessons), generated by
`tools/ml_guide_page.py` through `python3 tools/gen_site.py`. Linked from the AI-First Data Engineer
program page ("Free for everyone") and the AI for Data Engineers tab of the Study Library.

## Adding a new class
1. Open `class_log.py` and append a dict to `CLASSES`: `n`, `title`, `summary`, and `topics`.
2. For each topic list where it is taught: `ml:N` (Statistics & ML track lesson N), `py:N`, `de:N`,
   `gov:N`, or `guide:<slug>`. A topic with an empty list shows as a red **Gap** on the hub page.
3. Run `python3 tools/gen_site.py`, then check the hub page.

## Adding a companion lesson (to close a gap)
1. Write a self-contained script in `examples/` named `cN_<topic>.py` (synthetic data, seeded).
2. Append a lesson dict to `guide_lessons.py` (same keys as the others; `code` is the script name).
3. Run `python tools/mlguide/capture.py` with numpy, pandas, scipy, scikit-learn and statsmodels
   installed. It saves real outputs to `outputs.json` and rebuilds `handbook/ML-Class-Guide-Code.zip`.
4. Reference the lesson from `class_log.py` with `guide:<slug>`, then run `python3 tools/gen_site.py`.

Class materials (slides, notebooks, datasets) belong to the course provider and are not published;
the guide summarises topics in its own words and uses synthetic data.
