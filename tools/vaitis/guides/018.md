## What you need
- A paid Claude plan (Pro or higher).
- Claude on web, desktop or mobile. Reading a **local folder** needs the **desktop app**; a connected source (Google Drive, Notion and so on) works anywhere.
- A data source: a local folder of CSV, XLSX or JSON files, **or** a connected app (Google Drive, Notion, Airtable, Slack or a custom MCP server).

> There is nothing separate to install; the dashboard is an artifact Claude builds for you.

## Step 1: Prepare your data
**Local folder:** create a folder (for example `company-data`) and put your files in it, such as `sales-2026-q3.csv`, `customer-list.csv` and `product-inventory.xlsx`. Claude reads CSV, XLSX, JSON, plain text and Markdown.

**Connected app** (best for a dashboard a team keeps using):
1. In Claude, open the sidebar and go to **Connectors**.
2. Turn on the connector for your source (Google Drive, Notion, etc.).
3. Finish signing in. The dashboard now reflects the source whenever it changes.

## Step 2: Ask Claude to build the dashboard
Start a new chat:

```prompt Build the dashboard
Build me an interactive dashboard artifact from the folder ~/Desktop/company-data. Read all CSV and XLSX files in it and choose the most useful chart types for the columns. Include a Refresh button that re-reads the data and updates every chart, a chat box at the bottom that answers questions like "which region performed best this quarter?", and a "last refreshed" time. Design: clean, professional and minimal, with colours that work in light and dark mode. Layout: KPI cards at the top, charts in the middle, the chat box at the bottom, and the raw-data table collapsed by default.
```

Using a connected app? Change the first sentence, for example: "Build me an interactive dashboard artifact from my Google Drive folder called Company Data, using the Google Drive connector." Keep the rest.

Claude reads the data (or calls the connector), chooses the charts and adds the dashboard to your Artifacts.

## Step 3: Open and refresh it
Open the artifact from your Artifacts view. It re-reads the folder or connector so you see current data. The chat box runs as whoever is using it, so each person needs their own Claude access to ask questions.

## Step 4: Share it (Team or Enterprise)
On Team or Enterprise plans you can share it inside your organisation. People who open it sign in to the same organisation and it uses their own connectors and data. On Pro, the dashboard stays private to your account.

## Extra from Vaitis
- **Clean data first:** consistent column names and one header row make charts far more accurate. Ask: "List any columns with missing or inconsistent values before building."
- **Good starter KPIs:** total revenue, number of customers, average order value, growth versus last period.
- **Practise the skill:** SkillNavora's free Excel, SQL and Power BI lessons teach the same thinking behind good dashboards.
