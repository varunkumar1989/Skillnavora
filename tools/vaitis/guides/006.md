## What you need
- A Mac or Windows laptop.
- A paid Claude plan (Pro or higher). Claude Code and the advisor sub-agents run on your plan; no API key needed.
- Node.js 20 or newer (free).
- 5 minutes.

## Step 1: Install Claude Code
On **Mac**, open Terminal and paste:

```cmd Install Claude Code (Mac)
curl -fsSL https://claude.ai/install.sh | bash
```

On **Windows**, open PowerShell and paste:

```cmd Install Claude Code (Windows)
irm https://claude.ai/install.ps1 | iex
```

Then type `claude`, press Enter and sign in when asked.

> **"claude: command not found"?** Close and reopen the terminal, then try again.

## Step 2: Install Node.js
Roast Room runs a small local app that shows the 7 advisors around a table, and that app needs Node. Download version 20 or newer from nodejs.org and install it with the default settings. Check it worked:

```cmd Check Node
node --version
```

A number like `v20.x` means you are ready.

> **"node: command not found"?** Reinstall Node from nodejs.org and reopen the terminal.

## Step 3: Install the Roast Room skill
Open Claude Code and send:

```prompt Install Roast Room
Clone github.com/nateherkai/roast-room and set it up for me. Run git clone, go into the folder, check that the .claude/skills/roast-room folder exists, then run /skills so I can see all 7 advisor sub-agents loaded.
```

> **Advisors missing from /skills?** Say: "Reload the skills folder and run /skills again."

## Step 4: Start the room
In your terminal, inside the `roast-room` folder, run:

```cmd Start the room
npm start
```

Open this in your browser and keep the tab open. It is the live room where you watch the debate:

```link The room
http://localhost:4730
```

> **npm start fails?** Make sure you are inside the folder first (`cd roast-room`). If the page won't load, check the `npm start` terminal is still running, then refresh.

## Step 5: Run your first roast
Open Claude Code in the same folder (type `claude`) and send your decision:

```cmd Run a roast
/roast-room [your decision here]
```

Give the council what it needs. Example:

```prompt Example decision
/roast-room I run a D2C skincare brand making $40k a month with one full-time employee. Should I raise prices by 30%, launch a cheaper line, or spend the next 90 days only on content and keep prices flat? I have $25k in the bank. Success means $70k a month by March. I'm leaning towards the cheaper line because volume feels safer.
```

Always include: the decision, 2 or 3 options, your numbers (revenue, cash, team), your limits (deadline, budget), what success looks like and which way you lean. The Chair asks follow-up questions if something is missing.

!> A full 7-advisor council uses real plan credit (21 sub-agent runs). For smaller questions use:
- `/roast-room --quick [decision]`: 4 advisors, 2 rounds.
- `/roast-room --seats hormozi,buffett [decision]`: only the advisors you choose.
- `/roast-room ask hormozi [question]`: one answer from one seat.

## Step 6: Watch the debate and get your verdict
Each advisor argues from one area of business:

| Advisor seat | Focus | Question it asks |
|---|---|---|
| Jeff Bezos | Strategy and reversibility | Is this the right bet, and can you undo it? |
| Paul Graham | Product-market fit | Do people actually want it? |
| Alex Hormozi | Offer, pricing, sales | Will people pay? |
| Gary Vaynerchuk | Attention and marketing | Where will the eyeballs come from? |
| Dan Martell | People, hiring, your calendar | Who does this work? |
| Gino Wickman | Operations | Can the business run without you? |
| Warren Buffett | Cash, risk, capital | What does this do to the money? |

The advisors are AI personas based on these people's public writing and talks, not the people themselves. They score every option, weighted by how much their area matters to your decision, and the Chair limits the verdict if any seat flags a risk of ruin. You get a short verdict in Claude Code, a full report in the `sessions` folder and a one-click PDF in the room.

> **Run another decision:** open two terminals in the `roast-room` folder. In the first, run `npm start` to keep the room live. In the second, run `claude`, then `/roast-room` with the new decision. A full council takes 5 to 10 minutes.

## Extra from Vaitis
- **Treat it as a thinking partner, not an oracle.** The verdict is only as good as the numbers you give it.
- **Good decisions to test:** pricing changes, which course to launch next, hiring your first employee, or whether to run ads or grow organically.
- **Compare with the LLM Council guide** in this library, which uses different models instead of personas.
