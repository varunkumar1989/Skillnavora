## How it works
The council is five Claude sub-agents with different thinking styles. They answer separately, grade each other anonymously so nobody defends their own answer, and a chairman commits to one verdict.

```figure council-flow
```

## What you need
- A paid Claude plan (Pro or higher). Claude Code isn't on the free plan.
- Claude Code installed and signed in, or Claude on claude.ai.
- Nothing else: no API keys, MCP servers or scripts. It's a pure skill that runs on sub-agents.

## Step 1: Install LLM Council
**Path A: let Claude install it (easiest).** In Claude Code or claude.ai, send:

```prompt Install LLM Council
Please install this Claude skill. The SKILL.md file is at https://github.com/oliwoodman/llm-council-skill. Set it up as a global skill so I can use it in any project, and walk me through anything you need from me.
```

Claude fetches the file, creates `~/.claude/skills/llm-council/` and confirms it's ready. Restart Claude Code once.

**Path B: clone it yourself:**

```cmd Install with git
git clone https://github.com/oliwoodman/llm-council-skill ~/.claude/skills/llm-council
```

**Path C: one command, no git** (a fork with the same advisor structure):

```cmd Install with skill add
claude skill add --url https://raw.githubusercontent.com/automatorsplus/llm-council-skill/main/.claude/skills/llm-council/SKILL.md
```

## Step 2: Call a council
Start your message with the trigger phrase, then your question:

```prompt Run a council
council this: [your question or decision]
```

Examples:
- `council this: should I quit my job to build my SaaS full-time?`
- `council this: my agency makes $10k a month. Should I hire my first employee or stay solo?`
- `council this: should I raise my consulting rate from $50 to $100 an hour? Will I lose more clients than I gain?`
- `pressure-test this: I want to launch a paid founders' community at $29 a month. Here's my plan: [describe it]`

Claude runs the five advisors in parallel, then an anonymous peer review, then the chairman's verdict. A full council takes about 4 to 6 minutes.

## Step 3: Understand the verdict
Each advisor answers first through one lens:

| Advisor | Lens |
|---|---|
| The Contrarian | Hunts for the fatal flaw: what's missing and what will fail. Doesn't hedge. |
| The First-Principles Thinker | Asks whether you're solving the right problem and reframes it from scratch. |
| The Expansionist | Looks for the upside others missed, ignoring risk (that's the Contrarian's job). |
| The Outsider | Knows nothing about you or your field and reacts only to what's in front of it. |
| The Executor | Only cares what you do first: "what happens on Monday morning?" |

Next, all five grade each other **anonymously**, without knowing who wrote what, which keeps the review honest rather than defensive. Finally the **Chairman** commits to one verdict in about 250 words: the call (go, don't or conditional), the strongest reason, the biggest risk and a next step within 7 days. If Claude starts to hedge, the skill forces it to commit.

> **The Outsider is the most underrated advisor.** Run `council this: [your product description]` and it tells you what a first-time visitor won't understand, the way a stranger reads your landing page. That's often worth more than the other four together.

> **Want different AI models instead of one?** This skill uses five Claude sub-agents with different lenses. Andrej Karpathy's original LLM Council makes Claude, GPT, Gemini and Grok argue and review each other. It's a local web app, takes about 15 minutes to set up and needs an OpenRouter API key with roughly $5 to $10 of credit.

## Extra from Vaitis
- **Give it numbers:** revenue, savings, time available and deadline. Councils with real numbers give much sharper verdicts.
- **Career decisions work too:** "council this: should I switch from business analyst to product manager in the next 6 months?"
- **Then act:** turn the Chairman's 7-day next step into a calendar task straight away.
