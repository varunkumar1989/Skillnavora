## What you need
- A paid Claude plan (Pro or higher). Claude Code is not on the free plan.
- A Mac or Windows computer.
- Node.js 22.19 or newer. If it's missing, Claude installs it in Step 2.
- Under 5 minutes.

## Step 1: Install Claude Code
**Mac:** open Terminal (Cmd + Space, type Terminal, Enter) and paste:

```cmd Install Claude Code (Mac)
curl -fsSL https://claude.ai/install.sh | bash
```

**Windows:** open PowerShell (press Win, type PowerShell, Enter) and paste:

```cmd Install Claude Code (Windows)
irm https://claude.ai/install.ps1 | iex
```

Then type `claude` and sign in.

> **"command not found"?** Close and reopen the terminal, or restart your laptop.

## Step 2: Let Claude set up REA
Open Claude Code in any folder and send:

```prompt Set up REA
Clone the REA (Reverse Engineer Anything) repository from https://github.com/morluto/rea into a new folder called "rea", install all dependencies, set up the environment and confirm it is ready to run. Walk me through any settings or API keys I need to add.
```

Claude clones the project, installs dependencies, prepares the settings and tells you whether any API keys are needed and where to get them. Wait until it confirms setup is complete.

> **Clone failed?** Check your internet connection and send the message again.

## Step 3: Point REA at your first app
Replace the brackets with what you want to study:

```prompt Analyse an app
I want to use REA to reverse-engineer [APP OR FEATURE]. Explain how it works, break down its core features, and show me how I could rebuild it in my own project.
```

Example: "I want to use REA to reverse-engineer Notion's sidebar navigation…". REA scans the app, maps its structure and gives you a breakdown.

> **Start small:** one feature, not a whole app, and open-source apps first. The results are cleaner and you can judge quality quickly.

> **Not sure what to study?** Ask Claude: "Suggest 5 apps I could reverse-engineer with REA for my project." Some apps block analysis; if REA can't access one, try another or an open-source app.

## Step 4: Rebuild the feature
```prompt Build the feature
Use that breakdown to build this feature in my project. My project uses [YOUR STACK, e.g. React, Next.js, Tailwind]. Create the files, write the code and show me how to test it.
```

Claude writes the code based on what REA found.

> Ask Claude to explain REA's findings **before** building, so you learn as you go. Save every breakdown to build your own library of app blueprints. Beyond single features, you can study a dashboard pattern, revive an old app or rebuild an offline tool.

!> Use REA to learn how apps work and to build features in your own code. Don't copy anyone's proprietary code, designs or assets wholesale, and respect each app's terms of use and the law in your country.

## Extra from Vaitis
- **Good learning targets:** open-source apps such as Excalidraw (whiteboard), Cal.com (scheduling) or Plausible (analytics).
- **Write it up:** turn each breakdown into a short case study. It makes a strong portfolio piece for product and engineering interviews.
- **Pair with the PRD writer:** feed the breakdown into the SkillNavora AI PRD Writer to turn it into a product spec.
