## What you need
- Node.js 18 or newer and npm (only for self-hosting).
- A **Muapi.ai** account for the API key. The app is free, but generation runs through Muapi and is paid per use.
- macOS, Windows or Linux.

!> Only use photos, voices and footage you have the right to use. Lip-sync turns a photo plus any voice into a talking video, so never use it to impersonate a real person.

## Step 1: Choose how to run it
**Path A: hosted web version (no install).** Open muapi.ai/open-generative-ai, click **Settings**, paste your Muapi key (Step 2) and start.

**Path B: desktop app.** On the repository's **Releases** page download the `.dmg` (macOS), `.exe` (Windows) or `.AppImage` (Linux), install it and paste your key on first launch.

**Path C: self-host.** Clone the repository:

```cmd Clone the repository
git clone --recurse-submodules https://github.com/Anil-matcha/Open-Generative-AI.git
cd Open-Generative-AI
```

Set it up (plain `npm install` isn't enough; this builds the workspace packages first):

```cmd Set up
npm run setup
```

Launch it and open `http://localhost:3000`:

```cmd Launch
npm run dev
```

> The desktop app isn't signed, so macOS may say "cannot verify developer" (right-click → Open) and Windows SmartScreen may block it (More info → Run anyway). This is normal for small open-source projects.

## Step 2: Get and add your Muapi key
1. Sign up at muapi.ai.
2. New accounts often get trial credits, but the amount varies, so check your balance before generating.
3. Open **API Keys → Create Key** and copy it.
4. Paste it when the app asks. It's stored in your browser's local storage and sent only to Muapi.

## Step 3: Know the four studios
| Studio | What it does |
|---|---|
| Image Studio | Text-to-image and image-to-image across 50+ models (Flux, Midjourney, Ideogram, SDXL, Nano Banana 2, GPT-4o), with up to 14 reference images on supported models |
| Video Studio | Text-to-video and image-to-video (Sora 2, Veo 3, Kling v3, Wan 2.6, Seedance 2.0 and Pro, Hailuo 2.3, Runway Gen-3). Ratios 16:9, 9:16, 4:3, 3:4; usually 5, 10 or 15 seconds |
| Lip Sync Studio | Portrait + audio → talking video, or video + audio → lip-synced video. Nine models across the two modes |
| Cinema Studio | Preset camera, lens, focal length and aperture controls for when words alone don't give the look |

## Step 4: Make a talking video from a photo
1. Open **Lip Sync Studio** and choose portrait + audio mode.
2. Upload the photo.
3. Upload or record audio in the voice you want (or create it with a text-to-speech tool).
4. Choose a model: **Infinite Talk I2V** for realism or **LatentSync** for speed.
5. Set aspect ratio and duration.
6. Click **Generate**.

## Step 5: Make a cinematic video from a photo
1. Open **Video Studio** and choose image-to-video.
2. Upload the photo.
3. Add a prompt:

```prompt Cinematic motion
Slow cinematic push-in, warm sunset light, film grain, shallow depth of field.
```

4. Choose a high-quality model such as **Seedance 2.0 Pro** or **Kling v3**.
5. Set 16:9 and 5 to 10 seconds.
6. Click **Generate**.

## Extra from Vaitis
- **Control costs:** test prompts on cheaper, shorter, lower-resolution runs; switch to premium models only for the final version.
- **Prompt formula for video:** subject + action + camera movement + lighting + style (e.g. "a student opens a laptop, slow dolly-in, soft morning light, documentary style").
- **Label AI media** in captions when you publish realistic AI video.
