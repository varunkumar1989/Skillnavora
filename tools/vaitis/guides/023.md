## What you need
- Node.js 18 or newer and npm (or Docker).
- A coding tool with a custom endpoint: Claude Code, Codex CLI, Cursor, Cline, Copilot, Windsurf, Continue or any OpenAI-compatible tool.
- A browser for the dashboard.

## Step 1: Install OmniRoute
npm is simplest:

```cmd Install with npm
npm install -g omniroute
```

Or Docker:

```cmd Run with Docker
docker run -p 20128:20128 diegosouzapw/omniroute
```

Or download the desktop app (Mac, Windows, Linux) from omniroute.online. Check the npm install:

```cmd Check the version
omniroute --version
```

## Step 2: Start it
```cmd Launch OmniRoute
omniroute
```

It prints a dashboard address and an API endpoint, both on port **20128**.

## Step 3: Connect a few free providers
Open the dashboard, go to **Providers** and connect some free tiers:

```link Dashboard
http://localhost:20128/dashboard
```

| Provider | What you get | How to connect |
|---|---|---|
| iFlow | Kimi K2 Thinking, free | Browser sign-in |
| Qwen | Free Qwen models | Browser sign-in |
| Kiro | Free Claude 4.5, GLM-5 and MiniMax | AWS Builder ID, Google or GitHub |
| NVIDIA NIM | Free credits | Sign up |
| Groq | Fast free tier | API key |
| DeepSeek | Free tokens at sign-up | API key |
| GitHub Copilot | Free tier | GitHub sign-in |

Click **Connect** on any of them; no credit card. Connect several and OmniRoute uses them all.

!> Don't route Gemini CLI's free tokens through OmniRoute into other tools. Google's terms limit them to Gemini CLI itself, and using them elsewhere can get your account banned.

## Step 4: Point your coding tool at OmniRoute
Create a key under **Dashboard → Settings → API Keys**. The base URL for every tool is `http://localhost:20128/v1`.

**Claude Code:**

```cmd Route Claude Code
export ANTHROPIC_BASE_URL="http://localhost:20128/v1"
export ANTHROPIC_AUTH_TOKEN="your-dashboard-key"
claude
```

**Cursor, Windsurf or Antigravity:** set a custom endpoint to `http://localhost:20128/v1` in Settings.

**Codex CLI:**

```cmd Route Codex
export OPENAI_BASE_URL="http://localhost:20128/v1"
export OPENAI_API_KEY="your-dashboard-key"
```

**Any other OpenAI-compatible tool:** replace its openai.com base URL with `http://localhost:20128/v1` and use your dashboard key.

## Step 5: Build a routing combo
In **Combos**, build a chain. OmniRoute uses it in order and moves down when one runs out. Three starters:
- **free-only:** free providers such as Gemini 3 Flash, Kimi K2 Thinking and Qwen3 Coder Plus. Costs $0 while you stay on free tiers.
- **maximize-Claude:** your Claude Code subscription first, a cheap backup such as GLM 4.7 second, a free fallback such as Kimi K2 Thinking third.
- **always-on:** a longer chain (Claude, a GPT Codex model, GLM, MiniMax, then a free model) so runs rarely stop.

Save it and use its alias (for example `omniroute/free-only`) as the model name in your tool.

> Providers set free tiers and can change or end them. Treat a $0 setup as a bonus, not a guarantee.

## Step 6: Turn on compression
**Settings → Compression**, then pick a mode (fewer tokens for a little quality):

| Mode | Approx. savings | When to use |
|---|---|---|
| Off | 0% | Debugging OmniRoute itself |
| Lite | 15% | Safest |
| Standard | 30% | Good default |
| Aggressive | 50% | Long coding sessions |
| Ultra | 75% | Maximum savings, some quality loss |

## Extra from Vaitis
- **For learners on a budget:** the free-only combo is enough to practise coding with an AI assistant without a paid plan.
- **Keep keys safe:** your dashboard key controls paid providers too. Don't share it or put it in public code.
