## What it is and why it helps
Most AI companies offer a small free tier: a few million tokens a month or a few thousand requests a day. One tier alone is a toy; added together they come to roughly **10.1 billion tokens a month** across **87 providers** and **736 model families**. FreeLLMAPI stacks them behind **one OpenAI-compatible endpoint**:
- A **router** picks the best available model for each request.
- When a provider hits its rate limit, it **falls over** to the next one automatically.
- It **tracks usage per key** so you stay under every free cap.
- Your provider keys are **stored encrypted**.
- It also speaks **Anthropic's Messages API**, so Claude-based tools can use it too.

!> FreeLLMAPI's own disclaimer: it's for **personal experimentation and learning, not production**. Free tiers have no uptime guarantee and no top "frontier" models, speed varies, and quality dips late in the day as top models hit daily caps (they reset at UTC midnight). Before you serve real customers, switch to a paid API. Each provider's terms still apply when you route through it.

## What you need
- **Docker Desktop** (for the one-line or Compose install), **or** the desktop app for Windows or macOS.
- Free accounts and API keys from a few AI providers (the dashboard lists them; Google Gemini, Groq and others offer free keys).
- About 15 to 30 minutes.

## Step 1: Install it
**Option A: one line (Docker required).** It creates `~/freellmapi`, generates an encryption key, pulls the image and starts the container:

```cmd One-line install
curl -fsSL https://freellmapi.co/install.sh | bash
```

> Prefer to read a script before running it? Open https://freellmapi.co/install.sh first. Re-running it is safe; your `.env` and encryption key are kept.

**Option B: Docker Compose (Mac/Linux):**

```cmd Docker Compose install
git clone https://github.com/tashfeenahmed/freellmapi.git
cd freellmapi
ENCRYPTION_KEY="$(openssl rand -hex 32)"
printf "ENCRYPTION_KEY=%s\nPORT=3001\n" "$ENCRYPTION_KEY" > .env
docker compose up -d
```

**Option C: Windows.** The easiest path is the `.exe` installer on the project's **Releases** page. There's also a macOS app, and mobile apps on Google Play and the App Store.

## Step 2: Add your provider keys
1. Open the dashboard:

```link Dashboard
http://localhost:3001
```

2. On the **Keys** page, add the free API keys you've collected.
3. On **Fallback Chain**, drag providers into the order you prefer.
4. Copy your **unified API key** from the top of the Keys page. This one key is what every app uses.

## Step 3: Make your first request
```cmd Test with curl
curl http://localhost:3001/v1/chat/completions \
  -H "Authorization: Bearer freellmapi-your-unified-key" \
  -H "Content-Type: application/json" \
  -d '{"model": "auto", "messages": [{"role": "user", "content": "hi"}]}'
```

Every response includes an `X-Routed-Via` header showing which provider and model answered.

**Choose how the router picks** with the `model` field:

| Model value | Behaviour |
|---|---|
| `auto` | Router decides (default blend) |
| `auto:smart` | Prefers the most capable models |
| `auto:fast` | Prefers the fastest responses |
| `auto:reliable` | Prefers models with the best recent success rate |
| `auto:balanced` | Reliability first, then speed and capability |
| `auto:<profile>` | Uses a named chain, e.g. `auto:coding` |
| a model id | Uses one specific model, e.g. `gemini-2.5-flash` |

## Step 4: Use it from Python or any OpenAI tool
```python Python example
from openai import OpenAI

client = OpenAI(base_url="http://localhost:3001/v1", api_key="freellmapi-your-unified-key")
resp = client.chat.completions.create(
    model="auto",
    messages=[{"role": "user", "content": "Explain SQL joins in two sentences."}],
)
print(resp.choices[0].message.content)
```

Any tool with an "OpenAI base URL" setting works the same way: set it to `http://localhost:3001/v1` and use your unified key. Claude-based tools point to `http://localhost:3001` (they add `/v1/messages` themselves) with the same key.

## Step 5: Give your n8n chatbot a free AI brain
This connects FreeLLMAPI to the SkillNavora WhatsApp workflow (`whatsapp_ai_workflow.json`):
1. Open the **Ask Grok** node.
2. Change the URL to `http://<your-freellmapi-address>:3001/v1/chat/completions`.
3. In the body, change `model: 'grok-4.7'` to `model: 'auto'`.
4. Edit its Header Auth credential: name `Authorization`, value `Bearer freellmapi-your-unified-key`.

> **n8n must be able to reach FreeLLMAPI.** If n8n runs on the same computer in Docker, use `http://host.docker.internal:3001`. n8n Cloud can't reach your laptop's `localhost`; run FreeLLMAPI on a server and only expose it securely (it's a single-user proxy, so never leave it open to the whole internet).

## Step 6: Know the limits
- No top frontier models, variable speed and no uptime guarantee.
- Answers get weaker late in the UTC day as the best free models hit their caps, then reset at midnight UTC.
- **Free installs** receive the model catalogue monthly; **premium** ($19 a year) gets new models the same day.
- For anything customers depend on, move to a paid API.

## Troubleshooting
- **Forgot the server password?** Click **Forgot password?**; the one-time code is printed in the server log (`docker compose logs -f freellmapi`) and lasts 15 minutes.
- **Dashboard won't load from another device?** By default it only listens on `127.0.0.1`. On a trusted home network only, start with `HOST_BIND=0.0.0.0 docker compose up -d`.
- **Update:** `docker compose pull && docker compose up -d` (your data and `.env` are kept).
- **Uninstall:** `docker compose down -v`, then delete the data folder.
