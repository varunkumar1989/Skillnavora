## What it is and how it works
Almost every AI company gives away a small free tier: a few million tokens a month or a few thousand requests a day. One free tier on its own is a toy. Added together, the free tiers of **87 providers** come to roughly **10.1 billion tokens a month** across **736 model families** and **1,313 free endpoints** (1,137 chat, 29 image, 41 audio, 68 embeddings, 19 transcription, 6 video).

FreeLLMAPI is a small program you run on your own computer. It collects your free keys and gives you **one address and one key** that every AI tool can use:

```figure freellmapi-flow
```

**What happens on every request:**
1. Your tool (Claude Code, Cursor, your n8n bot) sends the request to FreeLLMAPI with your one **unified key**.
2. The **router** picks the best model in your chain that has a healthy key and is still under all its rate limits.
3. It decrypts that provider's key in memory and calls the provider.
4. If the provider says "too many requests" (429) or fails (5xx), the router **cools that key down** and **retries the next model** automatically.
5. The answer streams back to your tool. The `X-Routed-Via` header tells you which provider and model answered.

```figure freellmapi-fallback
```

**Main features in plain words:**
- **Speaks every common AI "language":** OpenAI (`/v1/chat/completions`, `/v1/responses`, `/v1/completions`, images, video, speech, transcription, embeddings), **Anthropic** (`/v1/messages`, so Claude Code works), **Gemini** (`/v1beta`, so Gemini CLI works) and **Ollama** (so Zed and JetBrains work).
- **Smart routing with six strategies** (`auto`, `auto:smart`, `auto:fast`, `auto:cheap`, `auto:reliable`, `auto:balanced`) plus your own named chains (`auto:coding`).
- **Fusion:** ask for the model `fusion` and several free models answer in parallel, then a judge model combines the best answer.
- **Sticky sessions:** a conversation stays on one model for 30 minutes, and an optional **context handoff** note briefs the next model if it has to switch.
- **Tool calling rescue:** when a free model writes a tool call as plain text, it's converted into a real tool call, so coding agents keep working.
- **Safety:** provider keys are encrypted (AES-256-GCM) in a local database; your apps only ever see one `freellmapi-…` key.
- **Dashboard:** manage keys, reorder the chain, try prompts in a playground and see speed charts. 60 languages, light and dark mode.
- **Runs anywhere Node 20+ runs:** Windows, Mac, Linux, even a Raspberry Pi (about 40 MB of memory when idle).

!> FreeLLMAPI's own rule: it's for **personal learning and experimenting, not production**. Free tiers have no uptime guarantee, speed varies, and quality drops late in the UTC day as the best free models hit their daily caps (they reset at midnight UTC). It's single-user: run it for yourself and never expose it to the internet. Before serving real customers, switch to a paid API.

## What you need
- **Windows or Mac:** the desktop app (easiest, no Docker). **Or** Docker Desktop (Mac, Windows, Linux) for the server version.
- Free API keys from a few providers. Good free ones to start: **Google AI Studio (Gemini)**, **Groq**, **Cerebras**, **Mistral**, **OpenRouter**, **Cloudflare Workers AI**, **NVIDIA NIM**, **Hugging Face** and **Z.ai**. The full list with limits is at freellmapi.co/models.
- Node.js 20+ if you want the one-command tool setup (`npx freellmapi …`).
- 20 to 40 minutes.

## Step 1: Install FreeLLMAPI
**Option A: desktop app (easiest).** Download the macOS `.dmg` (Apple Silicon or Intel) or the Windows `.exe` from the Releases page. It runs in your menu bar or system tray with the router and dashboard built in. There's no account or password: the only thing you need is the **unified API key** shown in the tray pop-up.

**Option B: one line (Docker required).** Creates `~/freellmapi`, generates an encryption key, downloads the image and starts it:

```cmd One-line install (Mac / Linux)
curl -fsSL https://freellmapi.co/install.sh | bash
```

> Prefer to read a script before running it? Open https://freellmapi.co/install.sh first. Running it again is safe: your settings and encryption key are kept.

**Option C: Docker Compose on Mac or Linux:**

```cmd Docker Compose install (Mac / Linux)
git clone https://github.com/tashfeenahmed/freellmapi.git
cd freellmapi
ENCRYPTION_KEY="$(openssl rand -hex 32)"
printf "ENCRYPTION_KEY=%s\nPORT=3001\n" "$ENCRYPTION_KEY" > .env
docker compose up -d
```

**Option D: Docker Compose on Windows (PowerShell):**

```cmd Docker Compose install (Windows PowerShell)
git clone https://github.com/tashfeenahmed/freellmapi.git
cd freellmapi
$Bytes = New-Object Byte[] 32
[Security.Cryptography.RandomNumberGenerator]::Create().GetBytes($Bytes)
$ENCRYPTION_KEY = -join ($Bytes | ForEach-Object { "{0:x2}" -f $_ })
"ENCRYPTION_KEY=$ENCRYPTION_KEY`nPORT=3001" | Out-File -Encoding utf8 .env
docker compose up -d
```

> Mobile apps exist for Android (Google Play) and iPhone (App Store), and there's an experimental Android Termux guide in the docs.

## Step 2: Add your free keys and get your one key
1. Open the dashboard (desktop app: tray icon → **Open Dashboard**):

```link Dashboard
http://localhost:3001
```

2. Server installs ask you to create an email and password the first time. The desktop app signs in by itself.
3. On the **Keys** page, add the free provider keys you collected. You can also paste a whole `.env` file to bulk-import them.
4. On **Fallback Chain**, drag providers into the order you prefer (for example fast Groq and Cerebras first, Gemini for harder tasks).
5. Copy your **unified API key** from the top of the Keys page. It starts with `freellmapi-`. This one key is all your tools need.

> You can manage provider keys from the terminal too: `npx freellmapi keys add groq`, `keys list`, `keys test groq`, `keys remove groq --id 7` (these use a dashboard session token in `FREELLMAPI_DASHBOARD_TOKEN`).

## Step 3: Test it once
```cmd Test with curl
curl http://localhost:3001/v1/chat/completions \
  -H "Authorization: Bearer freellmapi-your-unified-key" \
  -H "Content-Type: application/json" \
  -d '{"model": "auto", "messages": [{"role": "user", "content": "hi"}]}'
```

Choose how the router picks with the `model` value:

| Model value | What it does |
|---|---|
| `auto` | Router decides (default blend) |
| `auto:smart` | Prefers the most capable models |
| `auto:fast` | Prefers the fastest responses |
| `auto:cheap` | Budget-leaning (everything is free, so similar to balanced) |
| `auto:reliable` | Prefers the best recent success rate |
| `auto:balanced` | Reliability first, then speed and capability |
| `auto:<profile>` | Uses one of your named chains, e.g. `auto:coding` |
| `fusion` | Several models answer, a judge combines them |
| a model id | One specific model, e.g. `gemini-2.5-flash` |

## Step 4: Connect Claude Code (free)
Claude Code speaks Anthropic's format, and FreeLLMAPI speaks it too. The easiest way is one command that writes the settings for you and makes a backup first:

```cmd Set up Claude Code automatically
npx freellmapi setup-claude --url http://localhost:3001 --api-key freellmapi-your-unified-key
```

Add `--dry-run` to preview the change without writing anything.

**Even safer:** `launch` starts Claude Code with the key injected only into that run, so the key is never saved in a settings file:

```cmd Launch Claude Code with no key on disk
npx freellmapi launch --url http://localhost:3001 --api-key freellmapi-your-unified-key
```

**Manual way:** Claude Code needs the server **root** address (it adds `/v1/messages` itself):

```cmd Point Claude Code at FreeLLMAPI by hand
export ANTHROPIC_BASE_URL="http://localhost:3001"
export ANTHROPIC_AUTH_TOKEN="freellmapi-your-unified-key"
claude
```

> Free models are good for learning, small edits and explanations. For big refactors, the strongest models (and your paid Claude plan, if you have one) still do better.

## Step 5: Connect Codex CLI, Gemini CLI and other terminals
**Codex CLI** uses the Responses format at `/v1`:

```cmd Set up Codex CLI
npx freellmapi setup-codex --url http://localhost:3001 --api-key freellmapi-your-unified-key
```

Or run it with no key saved on disk: `npx freellmapi launch-codex --url http://localhost:3001 --api-key freellmapi-your-unified-key`.

**Gemini CLI** speaks Google's own format at the server root:

```cmd Point Gemini CLI at FreeLLMAPI
export GOOGLE_GEMINI_BASE_URL=http://localhost:3001
export GEMINI_API_KEY=freellmapi-your-unified-key
gemini
```

**Every other supported tool** uses the same pattern: `npx freellmapi setup-<tool> --url http://localhost:3001 --api-key <your key>`. It reads your live model list, backs up the tool's config and merges the new settings in, so your other providers stay.

## Step 6: Editors, autocomplete, ChatGPT and MCP
**Zed and JetBrains AI (Ollama mode).** Ollama emulation is off by default. Turn it on under **Keys → Agents**, choose `key-required` (needed for Docker) or `open-loopback` (this computer only), then point the editor's Ollama setting at `http://localhost:3001`.

**VS Code autocomplete (ghost text) with Continue.** FreeLLMAPI serves `/v1/completions` for inline suggestions:

```cmd Continue config (config.yaml)
models:
  - name: FreeLLMAPI Autocomplete
    provider: openai
    model: auto
    apiBase: http://localhost:3001/v1
    apiKey: freellmapi-your-unified-key
    useLegacyCompletionsEndpoint: true
    roles:
      - autocomplete
```

**Cursor** needs a public `https://` address (Cursor's servers call it), so run `setup-cursor` and follow its guide, and only expose the router through a secure tunnel you control.

**Tools that can't add a key header:** create a revocable **URL token** under **Keys → Agents** and use `http://localhost:3001/v1/t/<token>/chat/completions`. Never put your main key in a URL.

**MCP server (for Claude Code and other agents).** Turn on **Agent compatibility → MCP** on the Keys page, then:

```cmd Add FreeLLMAPI as an MCP server in Claude Code
claude mcp add --transport http freellmapi http://localhost:3001/mcp --header "Authorization: Bearer freellmapi-your-unified-key"
```

Agents can then ask a free model to do a side task and check which models are healthy mid-session.

**ChatGPT** can reach your router through a private **Secure MCP Tunnel** and an `ask_freellmapi` tool; follow the ChatGPT section of the agent recipes guide.

## Step 7: Use it from your own apps and Python
Any OpenAI library works by changing two settings:

```python Python with the OpenAI library
from openai import OpenAI

client = OpenAI(base_url="http://localhost:3001/v1", api_key="freellmapi-your-unified-key")
resp = client.chat.completions.create(
    model="auto",
    messages=[{"role": "user", "content": "Explain SQL joins in two sentences."}],
)
print(resp.choices[0].message.content)
```

LangChain, LlamaIndex and the official OpenAI and Anthropic SDKs all work the same way. You can also add your own local models (Ollama, LM Studio, llama.cpp, vLLM) as a **custom provider** on the Keys page.

## Step 9: Know the limits and the rules
- **Daily dip:** the best free models have the smallest daily limits. Once they're used up, answers come from smaller models until midnight UTC.
- **Speed varies:** Groq and Cerebras are very fast; others are slower.
- **Free tiers change** without notice. The router updates its model list from a signed catalogue twice a day. Free installs get each new model 30 days after it appears; premium ($19 a year or $49 once) gets it the same day. The router itself stays free and MIT-licensed.
- **Provider terms still apply.** The project's May 2026 review rated Groq, Cerebras, Mistral, OpenRouter, Zhipu, Ollama Cloud, OVH and AI Horde as likely fine for a personal proxy; Google Gemini, NVIDIA NIM, Z.ai and Cloudflare as "caution"; and **Cohere as "avoid"** (its terms forbid personal use). Rules of thumb: one account per provider, no reselling, don't share your endpoint with other people, and don't use free tiers as a paid production backend.

!> This is information, not legal advice. Read each provider's terms yourself.

## Troubleshooting
- **Forgot the server password?** Click **Forgot password?**; the one-time code is printed in the server log (`docker compose logs -f freellmapi`) and lasts 15 minutes. The desktop app has no password.
- **Logs:** Docker: `docker compose logs -f freellmapi`. Desktop app: tray menu → **Open Logs Folder**.
- **Dashboard won't open from another device?** It only listens on this computer by default. On a trusted home network only: `HOST_BIND=0.0.0.0 docker compose up -d`.
- **A tool says 404 or "model not found":** check root vs `/v1` (Step 5) and that the model is `auto` or a model listed at `/v1/models`.
- **Update:** `docker compose pull && docker compose up -d` (your data and settings are kept).
- **Uninstall:** remove the app (or `docker compose down -v`), then delete the data folder: `%APPDATA%\FreeLLMAPI\` (Windows), `~/Library/Application Support/FreeLLMAPI/` (Mac) or `~/.config/FreeLLMAPI/` (Linux).
