## How it works
Arena runs a tournament: many Claude agents attempt the same prompt in different ways, critique each other and drop out round by round, so only the strongest answer survives. It costs much more credit than one chat.

## What you need
- A Mac or Windows laptop.
- A paid Claude plan (Pro or higher). Claude Code and Arena's agents run on your plan.
- 2 minutes for setup.
- The GitHub link of the Arena skill (search GitHub for "Arena Claude skill" if you don't have it).

## Step 1: Install Claude Code
The only manual install; Claude handles the rest.

**Mac** (Terminal):

```cmd Install Claude Code (Mac)
curl -fsSL https://claude.ai/install.sh | bash
```

**Windows** (PowerShell):

```cmd Install Claude Code (Windows)
irm https://claude.ai/install.ps1 | iex
```

Type `claude`, press Enter and sign in.

> **"command not found"?** Close and reopen the terminal and try again.

## Step 2: Install the Arena skill
In Claude Code, send this with the Arena repository link:

```prompt Install Arena
Install the Arena skill from this GitHub repository: [paste the repository link]. Clone it, install it as a Claude skill with any dependencies it needs, then run /skills to confirm it is loaded.
```

When it finishes, `/skills` lists Arena.

> **Clone fails?** Send: "Retry the Arena install and show me the exact error if it fails." **Not in /skills?** Send: "Reload the skills folder and run /skills again."

## Step 3: Run Arena on a prompt
```prompt Run Arena
Use the Arena skill on this prompt: [your prompt: a coding problem, a piece of writing, a strategy question or a design decision, ideally one where your first attempt wasn't sharp enough]
```

## Step 4: Watch the 100 agents compete
1. Arena starts 100 small Claude agents, each with the same prompt.
2. Each answers in its own way, with different reasoning, structure and angle.
3. They review each other's answers and point out mistakes.
4. Weaker answers are eliminated round by round.
5. One winner survives, and that's what you see.

You watch the rounds in the terminal. The final answer comes with a short note on why it won.

## Step 5: Know when to use it
Arena uses far more credit than a normal run (100 agents instead of 1). Save it for when:
- the first answer was clearly wrong,
- the task is open-ended and the best answer isn't obvious,
- you're about to ship, publish or send something important,
- you've re-prompted 2 or 3 times and keep getting similar, average answers.

For simple questions, a normal Claude chat is enough.

!> Because it runs 100 agents at once, Arena uses a lot of your plan credit. Use fewer agents for smaller jobs: "Run Arena on this prompt with 20 agents instead of 100: [your prompt]".

> To use it again later, open Claude Code and send: "Use the Arena skill on this: [your prompt]".

## Extra from Vaitis
- **Great uses for learners:** the strongest answer to a tough interview question, a sharper resume summary, or the best structure for a PRD.
- **Free alternative to try first:** ask one Claude chat for "5 very different answers, then critique each and combine the best parts". It's cheaper and often good enough.
