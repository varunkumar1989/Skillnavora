## What you need
- **Docker Desktop** and **Git**. On Windows, set up **WSL2** first.
- A free **Pexels API key** (pexels.com/api) for stock footage.
- An AI provider and key for the script. Free options: Ollama (local), g4f, Pollinations, ModelScope. Paid options (DeepSeek, OpenAI) cost about a cent per video.
- **8 GB of RAM** realistically. 4 GB only works with everything in the cloud; a local Ollama model needs 8 to 16 GB.
- About 5 GB of free disk and 15 to 30 minutes for the first setup (the Docker image is about 3 GB).

!> You need **two** keys, Pexels and an AI provider. "Set up in 10 seconds" is only the command time; the first real install takes 15 to 30 minutes, mostly the Docker download.

## Step 1: Get your keys
**Stock footage (free):** sign up at pexels.com and copy the API key from your account.

**Script AI: choose one lane:**

| Lane | Providers | Cost | Notes |
|---|---|---|---|
| Free, cloud | g4f, Pollinations, ModelScope | $0 | Quality varies; can be unreliable |
| Free, local | Ollama | $0 | Needs 8 to 16 GB RAM; installed separately |
| Paid, reliable | OpenAI, DeepSeek, Moonshot, AIHubMix | About $0.001 per 60-second video | Best scripts |

For a first run, **DeepSeek** gives the best quality for the price (a few cents covers dozens of videos). For a strictly free path, **Pollinations** or **g4f** with Pexels footage gets you a finished video at $0.

## Step 2: Download and configure
```cmd Clone and copy the config
git clone https://github.com/harry0703/MoneyPrinterTurbo.git
cd MoneyPrinterTurbo
cp config.example.toml config.toml
```

On Windows use `copy` instead of `cp`. Open `config.toml` and fill in three things (use the provider block that matches your choice):

```toml config.toml
# 1. Stock footage
pexels_api_keys = ["YOUR_PEXELS_KEY_HERE"]

# 2. Which AI writes the script
llm_provider = "deepseek"   # or openai, moonshot, ollama, g4f, pollinations...

# 3. That provider's key and address (block name matches llm_provider)
[deepseek]
api_key = "YOUR_LLM_KEY_HERE"
base_url = "https://api.deepseek.com"
model_name = "deepseek-chat"
```

The file is well commented; each provider has its own block.

> **Free local lane:** set `llm_provider = "ollama"`, then in the `[ollama]` block set `base_url` to `http://host.docker.internal:11434/v1` and `model_name` to a model you've downloaded (for example `llama3.1:8b`). Run `ollama list` to check.

## Step 3: Launch
Use the prebuilt image (faster):

```cmd Launch (prebuilt image)
docker compose -f docker-compose.release.yml up
```

Or build locally (slower; only if you changed the code):

```cmd Launch (build locally)
docker compose up
```

The first run downloads about 3 GB, so allow 10 to 20 minutes. Two services start:
- Web interface: `http://localhost:8501`
- REST API with docs: `http://localhost:8080/docs`

> Manage it with `docker compose ps` (see both containers), `docker compose logs -f webui` (watch logs) and `docker compose down` (stop and clean up).

## Step 4: Make your first video
Open `http://localhost:8501`:
1. **Topic:** one keyword or short phrase, e.g. "health", "morning routines" or "space facts".
2. **Language and ratio:** English and **9:16** for Reels, Shorts and TikTok.
3. **Voice:** start with **en-US-AndrewNeural** or any Edge TTS voice (free and natural).
4. **Subtitles:** keep **edge** (fast, no GPU). Switch to **whisper** later if accuracy matters more than speed.
5. Click **Generate**. You'll see each stage: script, search terms, footage download, voiceover, subtitles and the final FFmpeg encode.

The video is saved to `storage/tasks/<task_id>/final-1.mp4`.

> **Chinese voices by default?** The project's maintainer is Chinese; just pick an en-US voice. **Empty video or no footage?** Almost always the Pexels key (check `storage/logs/`), or the topic is too abstract; try a more concrete keyword.

## Step 5: Automate with the REST API (optional)
API docs are at `http://localhost:8080/docs`. Every interface feature is an endpoint: submit a task, check its `task_id`, then download the MP4. Good for batch or scheduled runs.

!> The output is a **draft**, not ready to publish. Stock footage relevance varies, and abstract topics pull odd clips, so always preview. Pexels and Pixabay are royalty-free for most uses, but check each clip's licence before commercial or large-scale publishing (task logs list the source links).

## Extra from Vaitis
- **Concrete topics work best:** "5 Excel shortcuts", "what is SQL in 60 seconds", "3 free AI tools for students".
- **Add your brand:** edit the final video in CapCut or Canva to add your logo and a call to action.
- **Batch a week:** use the API to make 7 videos from 7 keywords in one go, then review and schedule them.
