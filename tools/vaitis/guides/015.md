## How it works
Three skills give Claude Code design judgement (direction, motion, polish), and two MCP servers give it hands and eyes: Figma to read your designs and Playwright to test the result in a real browser.

```figure ui-stack
```

## What you need
- Claude Code installed and signed in.
- Node.js 18 or newer.
- The **Figma desktop app** (the web version won't work for the Figma MCP) and a Figma **Dev or Full** seat.
- Any project folder to try the setup in.

**The five parts:** three skills (**Emil Kowalski**, **Impeccable** and **Taste**) are the design brain; two MCP servers (**Figma** and **Playwright**) are the hands and eyes.

## Step 1: Install the Emil Kowalski skill
This covers animation craft, easing and the small details that make an interface feel right.

```cmd Install the Emil skill
npx skills add emilkowalski/skills --agent claude-code
```

It adds six sub-skills to `.claude/skills/` in the current project:
- **emil-design-eng:** the main skill (UI polish, animation decisions, component design).
- **review-animations:** checks your animations against Emil's rules.
- **improve-animations:** returns a prioritised list of fixes.
- **find-animation-opportunities:** shows where motion helps and where it hurts.
- **prototype:** builds several genuinely different versions of a UI element.
- **A design-review skill** focused on design decisions.

They trigger automatically when you ask Claude to build, review or improve UI. To check, ask Claude "What skills do you have available?"

## Step 2: Install the Impeccable skill
Impeccable adds about 20 slash commands for typography, colour contrast, spacing and interaction states. Inside Claude Code run:

```cmd Install Impeccable
/plugin marketplace add pbakaus/impeccable
/plugin install impeccable@impeccable
```

The one you'll use most is `/polish`: a full clean-up pass on the current file covering typography, contrast, spacing, interaction states, focus rings and dialog behaviour. It's the fastest way to stop an AI-built page looking AI-built.

## Step 3: Install the Taste skill
Taste blocks generic AI design and draws on a curated set of well-designed sites. Choose one:

**Option A:** the standalone community version (strictest about avoiding generic output, most widely used):

```cmd Install Taste (option A)
npx skills add https://github.com/Leonxlnx/taste-skill --skill "design-taste-frontend"
```

**Option B:** a merged skill combining Emil, Impeccable and Taste without duplicates. Useful if the three separate skills overlap for you:

```cmd Install Taste (option B)
npx skills add h3nryprod01/design-taste
```

## Step 4: Set up the Figma MCP server
Install the official plugin:

```cmd Install the Figma plugin
claude plugin install figma@claude-plugins-official
```

Restart Claude Code, run `/plugin`, open the **Installed** tab, select **figma**, press Enter and finish the sign-in in the browser.

Then switch on Figma's server:
1. Open the **Figma desktop app**.
2. Open a Figma Design file.
3. With nothing selected, switch to **Dev Mode**.
4. In the right sidebar, enable **MCP Server**.
5. You'll see a confirmation that it's running.

Test it by selecting a frame in Figma and sending:

```prompt Convert a Figma frame
Convert my current Figma selection into a React component with Tailwind CSS.
```

## Step 5: Install the Playwright MCP server
Playwright lets Claude open your site in a real browser, take screenshots and check its own work.

```cmd Add Playwright MCP
claude mcp add playwright --scope user -- npx -y @playwright/mcp@latest
```

Or add it to `~/.claude.json` (or a project `.mcp.json`):

```json Playwright in .mcp.json
{
  "mcpServers": {
    "playwright": {
      "command": "npx",
      "args": ["-y", "@playwright/mcp@latest"]
    }
  }
}
```

Restart Claude Code. The first run downloads Chromium (about 200 MB, once). Run `/mcp` and check **playwright** is connected. Test:

```prompt Screenshot and check a page
Open my dev server at localhost:3000, take a screenshot and tell me whether the hero section looks broken.
```

## Step 6: Use the whole stack
One prompt now runs the full loop:

```prompt Build a landing page
Build a landing page for a fintech SaaS called "Vault": modern and minimal, with a strong hero, three feature cards, three pricing tiers and a footer. Use Next.js, Tailwind and shadcn/ui.
```

Behind the scenes: **Taste** reads the brief and sets a real design direction, **Emil** decides what should move and with which easing, **Impeccable** enforces typography, contrast, spacing and states, Claude writes the code within those rules, and **Playwright** opens the page at mobile, tablet and desktop sizes and flags anything broken. Claude keeps fixing until Playwright confirms it works.

With a Figma design ready:

```prompt Figma to production code
Convert the design in my selected Figma frame into production code, matching it pixel for pixel. Test it in the browser when done.
```

## Extra from Vaitis
- **Check accessibility too:** ask "Run an accessibility check with Playwright: contrast, focus order and labels."
- **Phone first:** always ask Playwright to test at 390 px wide; most of your visitors are on phones.
- **Portfolio idea:** rebuild one of your own old projects with this stack and show the before and after.
