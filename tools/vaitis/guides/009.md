## How it works
Eleven separate skills each handle one job on a YouTube channel. They share one voice file, so every script, title and reply sounds like you, and none of them can post to your channel.

```figure youtube-week
```

## What you need
- A paid Claude plan (Pro, Max, Team or Enterprise). The free plan doesn't include Claude Code.
- A Mac or Windows computer.
- About 10 minutes.

> These skills never touch your YouTube account and never post anything. Claude writes, plans and checks; you upload.

## Step 1: Install Claude Code
The only manual step, done once.
1. Open your terminal. Mac: press Cmd + Space, type Terminal, press Enter. Windows: click Start, type PowerShell, press Enter.
2. Paste the line for your computer and press Enter:

```cmd Install Claude Code (Mac)
curl -fsSL https://claude.ai/install.sh | bash
```

```cmd Install Claude Code (Windows PowerShell)
irm https://claude.ai/install.ps1 | iex
```

3. Close the terminal, open a new one, type `claude` and press Enter. Sign in with your Claude account in the browser that opens.

> The installer shows no progress bar; just wait. If `claude` says "command not found", open a new terminal and try again.

## Step 2: Send one install message
Paste the whole message into Claude Code and press Enter. Claude asks permission before running commands; choose **Yes**.

```prompt Install the YouTube Agent Skill
Install the YouTube Agent Skill for me from https://github.com/Jakeschincariol/youtube-agent-skill. I'm not technical, so do everything yourself and explain each step simply.

1. Check my operating system and whether git and Python 3 are installed. On a Mac, if either is missing, run xcode-select --install, tell me to click Install in the pop-up, and wait for me. On Windows, install missing ones with winget (Git.Git and Python.Python.3.12).
2. Download the repository and copy all 11 skill folders (every folder starting with yt- inside the skills folder) to my personal skills folder ~/.claude/skills/ so they work in every project. If git fails, download https://github.com/Jakeschincariol/youtube-agent-skill/archive/refs/heads/main.zip and unzip it instead.
3. Create the folder ~/.claude/youtube/ and copy templates/voice.md into it, so the file is at ~/.claude/youtube/voice.md.
4. Install yt-dlp so the /yt-viral skill can read public video lists. Try pip first; if that fails, use Homebrew on Mac or winget on Windows. If it still fails, tell me and continue.
5. Test the tools once with: python3 ~/.claude/skills/yt-script/hookscore.py --hook "I tried every AI video tool so you don't have to" (on Windows use python instead of python3).
6. Show me a simple table of the 11 skills with one line each on what they do.
7. Finish with these next steps as a numbered list: type /exit, then claude to restart; type /skills and check all 11 yt- skills are listed; set up my voice file.
```

> On a Mac, a pop-up may ask to install "command line developer tools". Click **Install**, wait, then tell Claude "done".

## Step 3: Restart and check
1. Type `/exit` and press Enter.
2. Type `claude` and press Enter.
3. Type `/skills` and press Enter.

You should see all 11: `yt-script`, `yt-package`, `yt-edit`, `yt-comment`, `yt-plan`, `yt-viral`, `yt-retention`, `yt-shorts`, `yt-seo`, `yt-chapters`, `yt-audit`.

> **/yt-script missing?** Type `/exit`, then `claude`. Still missing? Tell Claude: "Check that the yt- folders are inside ~/.claude/skills".

## Step 4: Teach it your voice
Every skill reads one voice file. Set it up once and every script, title and reply sounds like you.

If you already have videos:

```prompt Build my voice file from videos
Write my voice.md from these 3 videos and save it to ~/.claude/youtube/voice.md. Get the captions with yt-dlp; if that fails, tell me and I'll paste the scripts.
1. [LINK TO YOUR VIDEO]
2. [LINK TO YOUR VIDEO]
3. [LINK TO YOUR VIDEO]
```

If you have no videos yet:

```prompt Build my voice file from an interview
Interview me one question at a time, then write my voice.md and save it to ~/.claude/youtube/voice.md.
```

> A better voice file gives better output. Redo it any time with your 3 best videos.

## Step 5: Use the 11 skills
Type the command followed by your idea or file:

| Skill | What it does | Try |
|---|---|---|
| `/yt-script` | Turns one idea into a full script with 5 scored hooks from 21 hook formulas | `/yt-script 5 free AI tools that replace a video editor` |
| `/yt-package` | 10 title options plus a thumbnail idea for the best one | `/yt-package my video about free AI video editors` |
| `/yt-edit` | Where to cut (dead air, filler, retakes) with timecodes | Attach your transcript (.srt), then `/yt-edit` |
| `/yt-comment` | Sorts comments, drafts replies in your voice, picks one to pin | Paste comments, then `/yt-comment` |
| `/yt-plan` | Plans your week around the hours you really have | `/yt-plan I have 6 hours this week` |
| `/yt-viral` | Finds videos in your niche that beat their channel's average | `/yt-viral check these channels: [3 to 5 links]` |
| `/yt-retention` | Shows where viewers leave and why | Attach your YouTube Studio retention export, then `/yt-retention` |
| `/yt-shorts` | Finds Shorts inside a long video and writes a new first line for each | Attach the transcript, then `/yt-shorts` |
| `/yt-seo` | Description, tags and 3 search terms to target | `/yt-seo my video about free AI video editors` |
| `/yt-chapters` | Chapters from your transcript that YouTube will display | Attach the transcript, then `/yt-chapters` |
| `/yt-audit` | Reviews the whole channel and gives you ONE fix | `/yt-audit my channel: [YOUR CHANNEL LINK]` |

From a viral idea to a finished package in one go:

```prompt Viral idea to script to package
Use /yt-viral on these channels: [3 to 5 channel links in my niche]. Pick the best idea I could make this week. Then use /yt-script to write it in my voice, and /yt-package to give me titles and a thumbnail idea.
```

> Thumbnails come as a written brief (expression, framing, 3 words, background); you or a designer make the image. `/yt-edit` gives a cut list; you or an editor do the cutting.

> Hook scores are a guide, not a promise. If a skill needs a number it doesn't have, it asks you instead of inventing one.

> For transcript skills, download an `.srt` from **YouTube Studio → Subtitles** or any transcription tool.

## Extra from Vaitis
- **Weekly rhythm:** Monday `/yt-plan`, Tuesday `/yt-viral` + `/yt-script`, after filming `/yt-edit`, before upload `/yt-package` + `/yt-seo` + `/yt-chapters`, 48 hours after upload `/yt-comment`, monthly `/yt-audit`.
- **Repurpose:** run `/yt-shorts` on every long video and post the Shorts to Instagram Reels too.
