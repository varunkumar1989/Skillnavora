## How it works
Harvey uses Claude as its brain. It learns your product from your website, then keeps cycling: find matching businesses, research each one, write a personal email, send it through Instantly and handle replies until a meeting is booked.

```figure harvey-loop
```

## What you need
- A Mac or Windows computer.
- A paid Claude plan (Pro or Max). Max is better if Harvey will run all day.
- A paid **Instantly** plan to send the emails. Growth or higher includes the API access Harvey needs.
- About 10 minutes.

## Step 1: Install Claude Code
This is the only part you do by hand. After this, Claude does the setup for you.

**On Mac:**
1. Open **Terminal** (press Cmd + Space, type Terminal, press Enter).
2. Paste this line and press Enter:

```cmd Install Claude Code (Mac)
curl -fsSL https://claude.ai/install.sh | bash
```

**On Windows:**
1. Open **PowerShell** (press Start, type PowerShell, press Enter).
2. Paste this line and press Enter:

```cmd Install Claude Code (Windows)
irm https://claude.ai/install.ps1 | iex
```

**Then on both:**
1. Close the terminal and open a new one.
2. Type the command below and press Enter.
3. A browser window opens. Sign in with the account that has your paid Claude plan.

```cmd Start Claude Code
claude
```

> If Claude later asks to install Git or Python, say yes. Harvey needs them, and Claude can install them for you.

## Step 2: Let Claude install Harvey
In the same Claude session, send this one message:

```prompt Set up Harvey
Install Harvey for me from the start. Clone https://github.com/ethanplusai/harvey.git into a new folder, install everything it needs (including Python or Git if my computer is missing them), then run Harvey's setup wizard from start to finish. Train Harvey on my product using my website, connect my email tool and start it. Ask me for anything you need, and explain each step in simple words.
```

Follow along as Claude installs the parts and asks you a few questions.

> Harvey is a separate app that uses Claude as its brain, not a Claude plugin, so there is no `/skills` step. You confirm it works by opening its dashboard in Step 4.

## Step 3: Tell Harvey what you sell
The setup wizard asks a few simple questions. This is the part that makes it work:
- **Your product:** paste your website link. Harvey reads it and learns your product and ideal customer. No website? Type the answers instead.
- **Your ideal customer:** the type of business you want (industry, size, location).
- **Your email tool:** your Instantly API key, so Harvey can send. In Instantly: **Settings → Integrations → API Keys**.

!> Skip the LinkedIn option. It can get your LinkedIn account restricted. Harvey finds leads from web search and company websites instead.

> **Example:** you build websites. You tell Harvey that, and it finds local businesses that fit, researches each one and writes a genuinely tailored email for each, not a template.

> **401 error from Instantly?** The API key is wrong or your plan has no API access. Create a new key under Settings → Integrations → API Keys.

## Step 4: Start Harvey and watch the pipeline
When setup finishes, tell Claude "start Harvey", or run:

```cmd Start Harvey
harvey run
```

Harvey now works in the background. It:
- finds new leads that match your ideal customer,
- researches each one,
- writes a personal cold email for each,
- sends them through Instantly,
- reads replies and answers them to move towards a meeting,
- repeats on the schedule you set.

Open the live dashboard in your browser:

```link Live dashboard
http://localhost:5555
```

The dashboard shows every lead, campaign and reply. To stop Harvey, go back to the terminal and press **Ctrl + C**. Nothing is sent while it is stopped.

> Harvey runs while your computer is on and the terminal is open. Running it all day and night on a server is possible later, but you don't need it to start.

> **"command not found: harvey"?** Tell Claude: "the harvey command isn't found, fix it".

> **Not finding leads?** Free web search gets rate-limited. Serper gives 2,500 free searches to start; its cheapest paid plan is $50 for 50,000 searches. Ask Claude to add a Serper API key.

## Step 5: Protect your email reputation
Badly run cold email gets your address blocked. A few minutes here saves weeks of trouble.
- **Use a separate sending domain**, not your main company email. Example: getyourbrand.com instead of yourbrand.com.
- **Turn on Instantly warm-up** and leave it on for 2 to 4 weeks before real sending.
- **Start small:** 10 to 20 emails a day, then increase slowly.
- **Always respect opt-outs.** Harvey treats "stop" or "unsubscribe" as final. Keep it that way.

!> This is not legal advice. For large volumes or regulated industries, speak to a lawyer first. In India, the EU and the US, cold email has rules (consent, identification, opt-out); follow them.

> Emails going to spam is almost always a domain problem, not your writing. Check your domain setup and warm-up, and halve your daily volume.

## Extra from Vaitis: use Harvey for SkillNavora-style businesses
- **Course or coaching business:** ideal customer = "HR and L&D managers at 50 to 500 person companies in India". Offer a free workshop, not a sale, in the first email.
- **Measure it:** track open rate, reply rate and meetings booked each week. A reply rate under 1% means the targeting or offer needs work.
- **Connect to your chatbot:** send interested replies to your WhatsApp or Instagram bot (see the SkillNavora WhatsApp agent guide) so prospects get instant answers about fees and courses.
