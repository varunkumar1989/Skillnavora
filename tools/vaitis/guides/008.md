## How it works
Claude Code runs an open-source assistant project. MCP servers connect it to your calendar, email and notes, and the ElevenLabs MCP server gives it a voice, so it can read your morning brief out loud.

```figure jarvis-flow
```

## What you need
- A computer running macOS 13+, Windows 10 (version 1809+) or Linux (Ubuntu 20.04+ / Debian 10+).
- 4 GB of RAM or more and an internet connection.
- A paid Claude plan (Pro, Max, Team or Enterprise). Claude Code is not on the free plan.
- A GitHub account.
- An ElevenLabs account. The free tier gives about 10,000 voice credits a month.
- The GitHub link of the open-source assistant project you want to install.

!> Wherever you see `YOUR-REPO-URL` below, use the real link of the assistant project you chose. The steps are the same for any open-source assistant project.

## Step 1: Install Claude Code
Claude Code installs and runs everything else. Use the command for your system:

```cmd Install Claude Code (macOS / Linux / WSL)
curl -fsSL https://claude.ai/install.sh | bash
```

```cmd Install Claude Code (Windows PowerShell)
irm https://claude.ai/install.ps1 | iex
```

```cmd Install Claude Code (any system with Node.js 18+)
npm install -g @anthropic-ai/claude-code
```

Check the installation:

```cmd Check the install
claude --version
claude doctor
```

Start it. The first launch opens your browser to sign in:

```cmd Start Claude Code
claude
```

> **"command not found: claude"?** Close and reopen the terminal (the installer updates your PATH). Still stuck? `claude doctor` tells you what is wrong.

## Step 2: Give Claude the project
Create a folder for the assistant and open Claude Code inside it:

```cmd Open Claude Code in a new folder
mkdir jarvis && cd jarvis
claude
```

Send this prompt (with your real link):

```prompt Install the project
Clone this repository into the current folder, read its README, install all dependencies and get it running. Ask me for anything you need (API keys, settings) as you go: YOUR-REPO-URL
```

Claude downloads the files, installs dependencies and starts the project. When it needs something, such as a key, it stops and asks; reply in plain English.

> **No project chosen yet?** Search GitHub for open-source "Claude voice assistant" or "voice MCP" projects and use that link. The setup is the same.

## Step 3: Add your ElevenLabs voice
This is what makes the assistant speak.

**Get your API key:**
1. Sign in at elevenlabs.io.
2. Open your profile → **API Keys** → create a new key.
3. Copy it somewhere safe.

**Choose a voice:**
1. Open **Voices** or the **Voice Library**.
2. Preview a few and pick one.
3. Copy its **Voice ID**.

**Connect it.** The simplest way is the official ElevenLabs MCP server. Install **uv** (a small helper), then add the server to Claude Code:

```cmd Install uv and add ElevenLabs
curl -LsSf https://astral.sh/uv/install.sh | sh
claude mcp add elevenlabs --env ELEVENLABS_API_KEY=<your-key-here> -- uvx elevenlabs-mcp
```

Or, if your project uses a `.mcp.json` file, add this block with your key and voice ID:

```json .mcp.json
{
  "mcpServers": {
    "elevenlabs": {
      "command": "uvx",
      "args": ["elevenlabs-mcp"],
      "env": {
        "ELEVENLABS_API_KEY": "<your-key-here>",
        "ELEVENLABS_VOICE_ID": "<your-voice-id>"
      }
    }
  }
}
```

Then test it:

```prompt Test the voice
Use ElevenLabs for voice output with the voice ID I set. Say this out loud as a test: "Good morning, your assistant is online."
```

Restart Claude Code if it doesn't see the new server straight away.

!> Each voice clip uses ElevenLabs credits. The free tier is enough for testing; heavy daily use may need a paid plan.

## Step 4: Connect your tools
Link the assistant to what you use every day: calendar, inbox, dashboards, notes. Each tool connects as an MCP server, exactly like ElevenLabs. The pattern is always:

```cmd Add a tool
claude mcp add <tool-name> --env KEY=value -- <command-that-starts-the-server>
```

See what is connected:

```cmd List connected tools
claude mcp list
```

Then ask Claude to use the tools in your routine:

```prompt Wire the tools in
I've connected my calendar and email. Update the assistant so my morning brief uses both: what's on my calendar today and which emails still need a reply.
```

> Google Calendar, Gmail, Notion and Slack all have ready-made MCP servers. Search "[tool name] MCP server" for the install command and add it with `claude mcp add`. Start with one or two tools.

## Step 5: Run your first morning brief
```prompt Morning brief
Give me my morning brief out loud: what's pending, what's important, and which emails I haven't answered yet.
```

Instead of scrolling through 40 emails you hear a short summary of what needs you. When you like the format, ask Claude to save it as a reusable command or a scheduled routine you can start with one word each morning.

> **Being charged API rates on Pro or Max?** An `ANTHROPIC_API_KEY` in your environment is overriding your subscription. Run `unset ANTHROPIC_API_KEY` to use your plan.

> **MCP server not showing?** Restart Claude Code and run `claude mcp list`. **Install script returns 403?** Usually a region, proxy or VPN issue: try another network or the npm method.

## Extra from Vaitis
- **Keep keys private:** never paste API keys into a chat or commit them to GitHub. Keep them in `.env` or the MCP config on your own computer.
- **Useful routines:** "evening wrap-up" (what got done, what moves to tomorrow), "meeting prep" (read the next meeting's invite and recent emails with that person).
- **Free voice option:** for offline speech, ask Claude to add your computer's built-in text-to-speech as a fallback when ElevenLabs credits run out.
