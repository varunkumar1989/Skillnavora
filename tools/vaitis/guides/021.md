## What you need
- Node.js 18 or newer, and npm.
- Claude Code, or any coding tool with a custom endpoint setting.
- A browser for the dashboard.
- Ideally an existing Claude plan (especially Max). 9Router works best as the backup behind it.

## Step 1: Install and start 9Router
```cmd Install 9Router
npm install -g 9router
```

```cmd Start 9Router
9router
```

It prints a dashboard address and an API endpoint, both on port **20128**.

Prefer a guided 5-minute setup that walks you through providers? Use the starter kit:

```cmd Starter kit (optional)
git clone https://github.com/aiflowlearn/9router-starter-kit
cd 9router-starter-kit
./install.sh
./configure.sh
```

## Step 2: Open the dashboard
```link Dashboard
http://localhost:20128
```

You land on the **Providers** page with nothing connected.

## Step 3: Connect 2 or 3 providers
Click **Providers** and choose. A good starter set across three tiers:

| Tier | Provider | Cost | How to connect |
|---|---|---|---|
| 1. Your subscription | Claude Code | Your plan | Click **Connect** and sign in. 9Router tracks your 5-hour and weekly limits live. |
| 2. Cheap paid backup | GLM (Z.ai) | About $0.60 per 1M tokens | Sign up at z.ai, create an API key, paste it |
| 2. Cheap paid backup | MiniMax | About $0.20 per 1M tokens | Sign up at minimax.io, create a key, paste it |
| 3. Free fallback | iFlow | Free (Kimi K2 Thinking) | Browser sign-in |
| 3. Free fallback | Qwen | Free (Qwen models) | Browser sign-in |
| 3. Free fallback | Kiro | Free (Claude 4.5, GLM-5, MiniMax) | AWS Builder ID, Google or GitHub sign-in |

Each free connection is one browser click with no credit card. Providers set their own prices and can change them, so check their sites.

!> Don't add **Gemini CLI** to this chain for use in other tools. Google's terms limit free Gemini CLI tokens to Gemini CLI itself; routing them into Claude Code may get your account banned. The dashboard flags this next to Gemini CLI.

## Step 4: Build your fallback chain
In the dashboard, open **Combos → Create Combo**. A solid order for Claude Code users:
1. Your Claude Code subscription (used fully first).
2. A cheap backup when the limit runs out, such as GLM 5.2.
3. A free emergency fallback, such as Kimi K2 Thinking via iFlow.

Save it. Your plan does the heavy work, a few dollars of cheap overflow fills gaps, and free tiers catch the rest.

## Step 5: Point Claude Code at 9Router
Create a key in the dashboard under **Settings → API Keys**, then in your terminal:

```cmd Route Claude Code through 9Router
export ANTHROPIC_BASE_URL="http://localhost:20128/v1"
export ANTHROPIC_AUTH_TOKEN="your-9router-dashboard-key"
export ANTHROPIC_MODEL="claude-with-fallback"
claude
```

Replace `claude-with-fallback` with your combo's name.

## Step 6: Turn on RTK Token Saver
In the dashboard: **Settings → RTK Token Saver → Enable**. RTK compresses long tool outputs (file dumps, terminal logs, JSON) before they reach the model, saving about 20 to 40% of tokens depending on your work. Your source code is kept exactly; only the noise around it is compressed.

> For heavier compression, also enable **Caveman mode**. Together they can save around 65% on log-heavy sessions.

## Step 7: Check the fallback works
1. Use Claude Code normally until you near your 5-hour limit (the dashboard shows a countdown).
2. Watch the **current provider** indicator.
3. When the Claude limit runs out, it switches to your tier-2 provider (e.g. GLM 5.2).
4. Keep coding: same interface, different engine, no new sign-in.

## Step 8: Use it with other tools (optional)
- **Cursor:** custom endpoint `http://localhost:20128/v1` with your dashboard key.
- **Cline, Continue, RooCode or any OpenAI-compatible tool:** base URL `http://localhost:20128/v1`.
- **Codex CLI:**

```cmd Route Codex through 9Router
export OPENAI_BASE_URL="http://localhost:20128/v1"
export OPENAI_API_KEY="your-9router-dashboard-key"
```

## Extra from Vaitis
- **Quality varies:** backup models are cheaper but often weaker. For important changes, wait for your Claude limit to reset or review the backup's code carefully.
- **Compare:** OmniRoute (guide 023) and FreeLLMAPI (guide 025) do similar routing; pick one rather than stacking all three.
