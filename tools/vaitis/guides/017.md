## What you need
- A Claude.ai account, or Claude Code installed.
- About 60 seconds. No Python, Node or API keys.

## Step 1: Install Prompt Master
Choose where you want it.

**Path A: claude.ai (simplest)**
1. Open the repository (link above).
2. Click the green **Code** button, then **Download ZIP**.
3. Open claude.ai.
4. In the sidebar go to **Customize → Skills**.
5. Click **Upload** and drop in the ZIP.
6. Prompt Master now works in every chat.

**Path B: Claude Code (for developers).** Clone it into your global skills folder:

```cmd Install into Claude Code (all projects)
mkdir -p ~/.claude/skills
git clone https://github.com/nidhinjs/prompt-master.git ~/.claude/skills/prompt-master
```

Restart Claude Code. For a single project only, clone it inside that project instead:

```cmd Install into one project
git clone https://github.com/nidhinjs/prompt-master.git .claude/skills/prompt-master
```

**Path C: Cursor.** Same idea, different folder:

```cmd Install into Cursor
git clone https://github.com/nidhinjs/prompt-master.git ~/.cursor/skills/prompt-master
```

!> Do **not** put it in `~/.cursor/skills-cursor/`. That folder is reserved for Cursor's built-in skills, and third-party skills there break things.

## Step 2: Use it in four ways
All four use the same engine but enter different modes.

**1. Natural language (most common).** Just describe what you want:

```prompt Natural language
Turn this into a proper prompt: I want Claude to build a landing page for my dog grooming business
```

Prompt Master detects the target tool, chooses a structure, spots missing details (no colours, sections or tech stack) and returns a finished prompt.

**2. Explicit call**, for tighter control when the target isn't obvious:

```prompt Explicit call
/prompt-master
Target: Midjourney
Task: A cinematic hero shot of my product
```

**3. Decompiler mode**, to find what's wrong with an existing prompt:

```prompt Decompile a prompt
Decompile this prompt and tell me what's wrong with it: "Write me a blog post about AI. Make it engaging."
```

It names the problems and returns a rewritten version with the fixes explained.

**4. Cross-tool translation**, to move a prompt between tools:

```prompt Translate across tools
Translate this Midjourney prompt for Sora: "cinematic wide shot, golden hour, 35mm anamorphic, shallow depth of field"
```

> **Example result:** "help me build the landing page for my SaaS, it's like Linear but for lawyers" comes back as a full prompt with context, goal, style, tone, audience, tech stack, section order, file structure and a clear "stop when" condition, so the AI never needs to ask a follow-up question.

## Extra from Vaitis: the 6-part prompt checklist
Even without the skill, a strong prompt includes:
1. **Role:** who the AI should act as.
2. **Goal:** the single outcome you want.
3. **Context:** audience, background, constraints.
4. **Inputs:** the data or text to use.
5. **Format:** length, structure, tone, file type.
6. **Done when:** how the AI knows it has finished.
