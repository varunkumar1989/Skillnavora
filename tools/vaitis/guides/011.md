## What you need
- macOS, Windows or Linux.
- **Node.js 24.x or 26.x.** Node 22 and older fail; avoid Node 25.
- A modern browser (Chrome, Edge or Safari).

!> Every layer is public, open-source intelligence (OSINT); nothing is hacked or scraped from private systems. Some bundled data is for non-commercial use only, and third-party terms (such as Cesium ion and Google) apply. Read the repository's LICENSE before any commercial use.

## Step 1: Install with Pinokio (easiest)
Pinokio is a one-click installer, best if you aren't technical.
1. Download the Pinokio desktop app from pinokio.computer.
2. Open it and search for **God's Eye View**.
3. Click **Install** and wait about 2 minutes.
4. Click **Launch**. It opens in your browser with every data layer switched on.

## Step 2: Or install from the terminal
Open a terminal in an empty folder and run:

```cmd Install God's Eye View
git clone https://github.com/bilawalsidhu/gods-eye-view.git
cd gods-eye-view
npm ci
npm run dev
```

The first `npm ci` takes 2 to 5 minutes.

> If the dev server complains about your setup, run `npm run doctor`. It checks your Node version and settings.

## Step 3: Open the live map
```link The map
http://localhost:4173
```

The globe loads with all 15 layers:

| Layer group | What you see |
|---|---|
| Air | Live flights and military aircraft |
| Sea | Ships and submarine cables |
| Space | Satellites and space launches |
| Cameras and radio | About 3,600 public CCTV cameras and radio stations |
| Hazards | Earthquakes and active fires |
| Transport | Live buses, trains, ferries and road traffic |
| Infrastructure | Data centres and dams |

## Step 4: Add free upgrades (optional)
It works without any keys. Optional keys unlock more:
- **Cesium ion** (free community tier): the Google photorealistic 3D globe. Free for personal use.
- **AISStream** (free sign-up): real ship tracking instead of sample data.
- **NASA FIRMS** (free sign-up): real active-fire data instead of sample data.
- **OpenAI API key:** voice narration and AI notes, about $0.02 to $0.10 a minute, with a $5 hard cap.
- **TomTom or Google Maps:** sharper map tiles (metered, paid by use).

> Add the free Cesium ion key first. The photorealistic 3D globe is what makes this stand out from a flat map.

## Extra from Vaitis
- **Learning uses:** geography and current-affairs lessons, supply-chain case studies (ships and cables), and data-visualisation projects for your portfolio.
- **Use it responsibly:** don't use public camera feeds to track individuals. Use the map for awareness, research and learning.
- **Build your own layer:** ask Claude Code to add a new layer from any public dataset (for example, your city's air-quality readings).
