Introduction to Artificial Intelligence :: AI refers to systems that perform tasks associated with human intelligence, such as perceiving images, understanding language and making decisions. Most AI in products today is machine learning, which learns patterns from data.
History and Evolution of AI :: The field moved from rule-based and symbolic systems to expert systems, then statistical machine learning, deep learning from around 2012, transformer models from 2017 and today's generative models. Each shift changed what products could do.
Traditional AI vs Generative AI :: Traditional models classify or predict from data, such as flagging fraud. Generative models create new text, images, audio or code. Traditional AI outputs a label or number; generative AI outputs content that needs review.
Narrow AI vs General AI :: Narrow AI performs specific tasks well, such as translation or recommendation. General AI would match human breadth across tasks. Only narrow AI exists today, so products should be designed around specific tasks.
AI Applications Across Industries :: Examples include fraud detection in banking, recommendations in e-commerce, diagnostics in healthcare, document processing in insurance, support automation and demand forecasting in retail.
Machine Learning Fundamentals :: Machine learning algorithms learn patterns from data to predict or decide without explicit rules for every case. Quality depends mostly on data quality and on defining the target correctly.
Supervised Learning :: Supervised learning trains on labelled examples to predict labels for new data. Example: historical loan applications labelled repaid or defaulted, used to predict risk for a new applicant.
Unsupervised Learning :: Unsupervised learning finds structure in unlabelled data, such as clusters of similar customers or unusual transactions. Results need interpretation, because no correct answer is given.
Semi-Supervised Learning :: It uses a small labelled dataset together with a large unlabelled one. This helps when labelling is expensive, such as medical images labelled only by specialists.
Reinforcement Learning :: An agent learns by trial and error to maximise cumulative reward. It suits sequential decisions such as pricing or robot control, but needs a safe simulation or careful rollout.
Classification :: Classification predicts a category, such as spam or not spam, or churn or stay. Its output is usually a probability, which the product converts into a decision using a threshold.
Regression :: Regression predicts a continuous number, such as delivery time or demand next week. Errors are measured as average distance from the true value.
Clustering :: Clustering groups similar items without labels. It is used for customer segmentation and for finding natural groups in support tickets. Clusters must be named and checked by people.
Recommendation Systems :: Recommenders suggest items using collaborative filtering (what similar users chose), content features, or hybrid models. They need careful evaluation for diversity and for avoiding narrow feedback loops.
Predictive Analytics :: Predictive analytics uses historical data to forecast outcomes such as churn, demand or default. A forecast is only useful if someone acts on it, so define the intervention before building the model.
Feature Engineering :: Feature engineering creates informative inputs from raw data, such as days since last purchase. Good features often matter more than a more complex algorithm.
Training, Validation and Testing :: The model is trained on one set, tuned on a validation set and evaluated once on an unseen test set. Keeping the test set untouched gives an honest estimate of performance.
Model Training and Inference :: Training learns model parameters from data. Inference uses the trained model to make predictions on new inputs. Inference cost and latency matter in production even when training is done once.
Overfitting and Underfitting :: Overfitting memorises training noise and performs poorly on new data. Underfitting is too simple to capture the pattern. Compare training and validation performance to detect either.
Bias-Variance Trade-Off :: Simple models have high bias and miss patterns. Complex models have high variance and react to noise. The aim is the level of complexity that generalises best to new data.
Model Performance Metrics :: Classification uses accuracy, precision, recall, F1 and AUC. Regression uses mean absolute error and root mean squared error. Pick the metric that matches the business cost of each kind of error.
Precision, Recall and F1 Score :: Precision is the share of positive predictions that are correct. Recall is the share of actual positives found. F1 combines both. In fraud detection, recall often matters more; in automatic account blocking, precision matters more.
Confusion Matrix :: A confusion matrix tabulates true positives, false positives, true negatives and false negatives. It shows what kinds of mistakes a model makes, which a single accuracy number hides.
ROC-AUC :: The ROC curve plots true-positive rate against false-positive rate across thresholds. AUC is the area under it: 0.5 means chance and 1.0 means perfect ranking.
Deep Learning Fundamentals :: Deep learning uses multi-layer neural networks that learn features directly from large data, such as images or text. It needs more data and compute than classical methods.
Neural Networks :: Neural networks connect layers of units with weights. Training adjusts the weights with backpropagation and gradient descent to reduce error.
CNN, RNN and LSTM :: CNNs process images using local patterns. RNNs process sequences step by step. LSTMs handle longer dependencies in sequences. Transformers have largely replaced RNNs for language tasks.
Transformers :: Transformers process sequences in parallel using attention. They underpin modern language and multimodal models, and they scale well with data and compute.
Attention Mechanisms :: Attention lets the model weigh which parts of the input matter for each output. It is the reason models can relate a word to a distant word in the same document.
Natural Language Processing :: NLP covers understanding and generating human language, from tokenisation and classification to question answering. Large language models now handle most NLP tasks in products.
Computer Vision Fundamentals :: Computer vision classifies, detects and segments content in images and video. Applications include document scanning, quality inspection and product tagging.
AI Model Lifecycle :: The lifecycle covers problem framing, data collection, training, evaluation, deployment, monitoring and retraining. The PM owns framing, the success definition and the monitoring plan.
