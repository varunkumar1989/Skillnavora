@S|25|End-to-End Practical Capstone Projects|Twelve portfolio projects. Each must include the full deliverable checklist below, so the work reads like a real product case.
Build an E-commerce Product Strategy. :: Define target shoppers, positioning, growth levers (search, recommendations, checkout) and a prioritised roadmap with metrics.
Design a Fintech Payment Product. :: Cover onboarding and KYC, payment flow, fraud and risk controls, compliance, reliability targets and merchant or consumer value.
Build a Product Analytics Dashboard. :: Choose a north star and input metrics, define events, build funnel and retention views, and document how each metric drives a decision.
Create a Customer Onboarding Optimisation Plan. :: Map the activation journey, find drop-offs from data, propose experiments and set success targets.
Develop an AI Customer Support Assistant. :: Scope intents, knowledge sources, escalation to humans, quality and safety evaluation, and deflection and satisfaction metrics.
Design a RAG-Based Enterprise Knowledge Assistant. :: Specify sources, permissions, chunking and retrieval design, citation behaviour, evaluation set and monitoring.
Build an AI Document Intelligence Product. :: Extract and validate fields from documents, handle low-confidence cases with review, and measure accuracy and time saved.
Design an AI Recommendation Engine. :: Choose signals and approach, cold-start handling, diversity and fairness, offline and online evaluation, and business metrics.
Create an AI Customer Complaint Management System. :: Classify, route and summarise complaints, set priorities and SLAs, include human review and compliance tracking.
Build a Multi-Agent Business Automation Workflow. :: Define agent roles, tools, permissions, hand-offs, approval points, failure handling and cost limits.
Develop an AI Sales Assistant. :: Support prospecting, call preparation and follow-up with CRM grounding, guardrails and pipeline-impact metrics.
Create an AI-Powered Product Analytics Assistant. :: Let users ask data questions in natural language with safe SQL generation, verification and clear lineage of answers.
