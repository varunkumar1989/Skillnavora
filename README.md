# Skillnavora

Website for [skillnavora.in](https://www.skillnavora.in), by Varun Kumar. Plain HTML, hosted free on Cloudflare Pages.

## Edit your contact details

Open `index.html`, find the `SITE = { ... }` block near the top, fill in your email, phone, WhatsApp number and social links, then commit. Empty values are hidden on the site. Phone numbers work with or without `91`, and links work with or without `https://`.

## Logo

`assets/logo-mark.svg` is the compass icon (used in the header, footer and browser tab). `assets/skillnavora-logo.svg` is the full logo with the wordmark. `assets/compass-original.png` is the original icon you uploaded.

## Cloudflare Pages settings

| Setting | Value |
|---|---|
| Production branch | `main` |
| Framework preset | None |
| Build command | *(leave empty)* |
| Build output directory | `/` *(leave empty)* |

Every commit to `main` redeploys the site automatically.
