Best free resources for this course

  • scikit-learn User Guide (official): Every algorithm in the course, with examples.
  • SciPy statistical functions (official): ttest_1samp, ttest_rel, ttest_ind, f_oneway, chi2_contingency and more.
  • statsmodels documentation (official): OLS summaries, VIF, GLMs and time series.
  • pandas User Guide (official): Building analytics files: groupby, pivot_table, merge, dates.
  • An Introduction to Statistical Learning, with Python (free book): The standard free textbook for this syllabus.
  • Google Machine Learning Crash Course (free): Short lessons on loss, gradient descent, generalisation and classification metrics.
  • OpenIntro Statistics (free book): Hypothesis testing, CLT and inference explained simply.
  • Kaggle Learn: Intermediate Machine Learning (free): Missing values, categorical variables, pipelines, cross-validation.
  • Kaggle datasets: Practice data for the weekly regression and KNN assignments.
