Put all the study material on Netlify

The whole website is static HTML, so Netlify can host every lesson, PDF and course straight from your GitHub repository.

Open Netlify ↗Netlify docs ↗

Steps

  1. 1
    Open app.netlify.com → Add new site → Import an existing project → GitHub → choose the skillnavora repository.
  2. 2
    Branch to deploy: main. Build command: leave empty. Publish directory: . (a single dot). The netlify.toml in the repository already says this.
  3. 3
    Click Deploy. Every page, lesson, PDF and course loads from Netlify, and every push to GitHub redeploys automatically. On Netlify the front page is the Study Hub with four tabs: AI Product Management, AI for Data Engineers, AI Engineer and GenAI Launchpad (the normal website home is at /home).
  4. 4
    Optional: Domain management → add your domain and follow the DNS steps; HTTPS turns on automatically.
  5. 5
    Drag-and-drop alternative: download the repository as a ZIP from GitHub, unzip, and drop the folder onto app.netlify.com/drop (very large PDFs may take a few minutes).

What to know

  • Works on Netlify: all study material: programs, handbooks, every lesson and PDF, the AI Skills Academy and interactive pages, practice tests, Practice Lab, PRD library, tools and learning sites, the details form (it falls back to WhatsApp/email if the lead API is missing).
  • Needs Cloudflare Pages (or a rewrite): the live AI tools (AI Tutor, PRD Writer, PM Toolkit, Speaking Coach feedback) and the lead API run as Cloudflare Pages Functions in functions/api/. On Netlify, keep these on Cloudflare and point to them, or ask to have them converted to Netlify Functions.
  • Files: the study material is roughly 350 MB, mostly PDFs. Netlify's free plan allows this; keep individual files under 100 MB (all are well below).
  • Security headers and redirects: the existing _headers and _redirects files use Netlify's format too, so they work as they are.
