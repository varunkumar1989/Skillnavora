AI Evals for Product Managers (13 classes)

An eval is a repeatable test that measures how well an AI feature does its job on a fixed set of examples, with a clear way to score each answer. It's the quality bar, the launch gate and the product spec for AI.

All classes (interactive)Course pagePDF
  1. Basic Class 1: What an eval is, and why PMs own itUnderstand evals as the unit test, the quality bar and the product spec for AI features.
  2. Basic Class 2: Defining success: criteria, rubrics and failure modesTurn a fuzzy goal ('helpful answers') into criteria anyone can score the same way.
  3. Basic Class 3: Building the eval dataset (golden set)Create a test set that represents real users, including the hard and risky cases.
  4. Intermediate Class 4: Grading methods: code, humans and LLM-as-judgeChoose the cheapest grader that measures what matters, and know when to use humans.
  5. Intermediate Class 5: Metrics for common tasks: classification, extraction and summariesPick the right number for the job, and calculate it correctly.
  6. Intermediate Class 6: Calibrating an LLM judgeMake sure an AI grader agrees with your experts before you trust its scores.
  7. Intermediate Class 7: Comparing versions: regression tests and sample sizeTell a real improvement from noise when you change a prompt, model or retrieval setting.
  8. Intermediate Class 8: Error analysis: finding what actually breaksRead outputs systematically, name the failure modes and fix the biggest ones first.
  9. Intermediate Class 9: Evaluating RAG (retrieval-augmented generation)Measure retrieval and generation separately, so you know which half to fix.
  10. Advanced Class 10: Evaluating agents and tool useMeasure multi-step AI agents on outcomes, the path they took, cost and safety.
  11. Advanced Class 11: Safety, responsible AI and red-teamingTest for harm, privacy leaks, bias and jailbreaks before attackers and journalists do.
  12. Advanced Class 12: Online evals: A/B tests, monitoring and regression gatesConnect offline scores to real user value and catch quality drops in production.
  13. Advanced Class 13: Eval ops: tools, cost, the AI PRD and your capstoneRun evals as a product practice: tooling, budgets, documentation and team rituals.
