11 AI tools every product manager should learn

The AI tools PMs use for research, writing, prototyping and automation, what each is best for, and the order to learn them in.

By Varun Kumar · 7 min read

AI tools now cover most of a PM's week: research, writing, design, prototyping and the repetitive work in between. You don't need all of them. You need to know which tool fits which job, and to be fluent in a few. Here's how the AI Tools Lab groups them.

Thinking and writing: Claude

Use Claude for interview synthesis, PRD drafts and critique, competitor research and data analysis. Projects keep your product context in one place, and connectors bring in Gmail, Calendar, Drive and Slack. Start here: it pays off the fastest.

Building: Claude Code, Lovable and Replit

  • Claude Code reads and edits real projects, pushes to GitHub and deploys prototypes. Best when you want full control.
  • Lovable goes from a prompt to a web app with a database, login and payments. Best for fast MVPs.
  • Replit builds and hosts full-stack apps in the browser. Good for quick internal tools.

Design: Figma and Figma Make

Design screens, build click-through prototypes and run workshops in FigJam. Figma Make generates working prototypes from a design, and Figma's MCP server lets Claude Code build from your designs.

Docs: Notion and PRD tools

Keep a product hub in Notion, write and critique PRDs with AI, and turn specs into tickets automatically.

Automation: Zapier, Make and n8n

Connect Gmail, Slack, Sheets and forms so routine work runs by itself. Zapier is the easiest to start with, Make is better for visual multi-step flows, and n8n is the most flexible and can run on your own server.

Customer-facing AI: chatbots and voice agents

WhatsApp and website chatbots answer customers with a safe handoff to people. Voice agents built on platforms like Vapi or Retell answer calls and book appointments for clinics, salons and shops.

Learn concepts, not buttons: triggers, tools, memory, evaluation and permissions last longer than any interface.

The order we recommend

Claude first, then Figma, then one builder (Lovable or Claude Code), then one automation tool. Add chatbots and voice agents when you're ready for a capstone. Every class is free in the AI Tools Lab.
