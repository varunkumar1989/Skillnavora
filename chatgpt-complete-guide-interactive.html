Lesson 1

ChatGPT in November 2026: apps, plans, models and built-in tools

Where ChatGPT runs (web, desktop with Codex, phone, browser), what each plan includes, how to choose a model, and the built-in tools: search, deep research, canvas, images, voice and agent.

Checked against official sources in November 2026. Lessons build on each other.
In plain words. ChatGPT is one assistant with a toolbox. You type a request, and it decides (or you choose) whether to just answer, search the web, write in a canvas, make an image, or act as an agent in a browser.

Key ideas

ChatGPTOpenAI's assistant, on the web (chatgpt.com), desktop, mobile and inside other apps.
Model pickerThe menu where you choose the model or mode (fast or thinking). Names change often, so read the short descriptions in the menu.
SearchLooks up current information and cites sources.
Deep researchA longer, multi-step investigation that returns a cited report.
CanvasA side-by-side editor for writing and code you can edit with ChatGPT.
AgentChatGPT working on its own computer and browser to complete multi-step tasks, asking before important actions.

How it works

Pick a plan→Open web, desktop or phone→Choose model / mode→Use a tool if needed→Review sources and output

1. Where ChatGPT runs

AppBest for
chatgpt.com (web)Everyday chat, files, search, canvas, images, projects
Desktop app (macOS, Windows)Chat plus Codex for coding (OpenAI merged the Codex app into the desktop app in July 2026), working with apps on your computer
Mobile appVoice conversations, camera and photos, quick questions
ChatGPT AtlasOpenAI's web browser with ChatGPT built in, including agent mode on web pages
CodexCoding agent in the cloud, the terminal (Codex CLI), IDEs and the desktop app

2. Plans in plain words

OpenAI offers Free, Go, Plus and Pro for individuals, and Business, Enterprise and Edu for organisations. Higher plans give more usage, access to the most capable models, longer deep research and more agent runs. Prices and limits change; check chatgpt.com/pricing for your country.

Good to know. Business, Enterprise and Edu workspaces have admin controls: admins decide which plugins, apps and memory features members can use, and business data is not used for training by default.

3. Choosing a model or mode

  • Open the model picker at the top of the chat. You will usually see a fast option for everyday work and a thinking option that reasons longer for hard problems.
  • Use the thinking mode for maths, multi-step analysis, careful code and planning; use the fast mode for drafts and quick answers.
  • Model names change often (OpenAI released several new models in 2026), so read the one-line description in the picker rather than memorising names.

4. Built-in tools

ToolUse it forExample prompt
SearchAnything recent; cites sources"What are the newest UPI rules for merchants? Cite official sources."
Deep researchA report from many sources"Research the AI PM job market in Bengaluru: top companies, skills asked, salary ranges, with sources."
CanvasEditing a long document or code together"Open a canvas and draft my product case study; I will edit section by section."
ImagesCreating and editing images"Make a clean infographic of the 5 steps of a Git workflow."
Data analysisWorking with spreadsheets and CSVs using code"Analyse this sales CSV and chart revenue by month."
VoiceTalking hands-free, practising interviews"Ask me five PM interview questions and give feedback after each."
AgentMulti-step tasks on websites"Find three co-working spaces near Koramangala under Rs 8,000 a month and compare them in a table."

5. Your first 15 minutes

  1. Sign in at chatgpt.com and open your profile menu, then Settings.
  2. Under Settings › Personalization, add custom instructions (Lesson 2) and check that memory is set the way you want (Lesson 3).
  3. Ask: "I am a data analyst. Give me a 4-week plan to learn GitHub, with one practice task per week."
  4. Turn on search and ask a question about something that changed this month; open two of the sources.
  5. Browse Plugins in the sidebar to see what you can connect (Lesson 4).

Common mistakes and fixes

MistakeFix
Treating an answer about recent events as current without searchTurn on search and ask for sources and dates.
Using the thinking mode for every tiny taskUse the fast mode for drafts; save thinking for hard problems.
Letting an agent buy or send things without checkingAgents ask before important actions; read each step before you confirm.

Practice

  1. Ask the same planning question in the fast and thinking modes and compare quality and time.
  2. Run one deep research report on your target role and verify three sources.
  3. Use canvas to rewrite your LinkedIn About section, editing one paragraph at a time.

Quick check

Which app gained Codex in July 2026?

The ChatGPT desktop app (OpenAI merged the Codex app into it).

When should you use deep research instead of normal search?

When you need a report that combines many sources and steps, not a quick fact.

Why read the model picker descriptions instead of memorising model names?

Because OpenAI changes model names often; the descriptions tell you which is fast and which reasons longer.

Lesson 2

Custom instructions, personality and Projects

Tell ChatGPT who you are once, choose its tone, and organise work in Projects with their own files, instructions and project-only memory.

Checked against official sources in November 2026. Lessons build on each other.
In plain words. Custom instructions are your standing brief. A Project is a dedicated room for one goal: its own files on the shelf, its own rules on the wall, and, if you want, its own memory that never leaves the room.

Key ideas

Custom instructionsAccount-wide text that tells ChatGPT about you and how to respond, applied to new chats.
PersonalityA preset tone (for example more concise or more friendly) you can choose in personalization settings.
ProjectA container for related chats, files and instructions.
Project instructionsRules that apply only inside one project and take priority over your global custom instructions.
Project-only memoryA project setting that uses context only from chats inside that project, not your global memories.
Temporary chatA chat that does not use or create memories and is not kept in history.

How it works

Custom instructions (you)→Project (the goal)→Project files + instructions→Chats inside the project

1. Set custom instructions

  1. Open your profile menu, then Settings › Personalization.
  2. Fill in what ChatGPT should know about you (role, goals, context) and how you want it to respond (length, tone, format).
  3. Optionally pick a personality preset for tone.
  4. Save. New chats use the instructions; existing chats keep their earlier context.
Example custom instructions
About me: Business analyst in Pune moving into product management. I use Excel, SQL and Jira.
How to respond: Plain English, bullet points first, one Indian example, under 250 words unless I ask
for more. Show calculations. If you are not sure, say so and suggest how to check.

2. Create a Project

  1. Select Projects (or New project) in the sidebar and name it, for example "Data PM job hunt".
  2. Choose the memory mode when you create it: default (can use your saved memories) or project-only (uses only chats inside this project). You can change it later in project settings where your plan allows.
  3. Add files: resume, target job descriptions, notes. Every chat in the project can use them.
  4. Write project instructions: "You are my interview coach. Ask one question at a time and score my answer out of 5."
  5. Start chats inside the project. Move existing chats in by dragging them or using the chat's menu.
Good to know. Shared projects switch to project-only memory automatically, so nobody's personal memory is exposed to collaborators. On Business, Enterprise and Edu, check with your admin which project features are on.

3. Which setting wins?

SettingApplies toNotes
Custom instructionsAll your chatsInside projects, project instructions take priority; on some Enterprise and Edu workspaces only project instructions apply in projects
Project instructionsChats in that projectBest place for task rules and roles
Saved memoryChats that use memoryNot used by project-only projects or temporary chats
Temporary chatOne chatNo memory used or created, not kept in history

Common mistakes and fixes

MistakeFix
Writing personal facts in project instructions you will shareKeep personal context in custom instructions; share only task rules in the project.
Using one project for unrelated goalsCreate one project per goal so files and memory stay relevant.
Expecting old chats to pick up new instructionsStart a new chat after you change instructions.

Practice

  1. Write custom instructions in under 100 words and test them with two questions.
  2. Create a project with project-only memory, add two files and run an interview-practice chat.
  3. Compare an answer in a normal chat and in a temporary chat for the same question.

Quick check

Where are custom instructions?

Settings, then Personalization.

What does project-only memory do?

The project uses context only from its own chats, not your global saved memories or other projects.

What happens to memory when you share a project?

It switches to project-only memory automatically.

Lesson 3

ChatGPT memory: saved memories, chat history and how to control both

The two memory settings (reference saved memories and reference chat history), how to view and delete what ChatGPT remembers, temporary chats, and privacy habits.

Checked against official sources in November 2026. Lessons build on each other.
In plain words. ChatGPT has two kinds of memory. Saved memories are sticky notes you (or ChatGPT) deliberately pin up. Chat history is ChatGPT glancing back through your old conversations for useful context. You can turn each one off separately.

Key ideas

Reference saved memoriesUses details ChatGPT has explicitly saved, often because you asked ("remember that…"). Kept until you delete them.
Reference chat historyLets ChatGPT use information from past chats. Less fixed: what it draws on can change over time.
Manage memoriesThe list of saved memories in settings, where you can delete one or all.
Temporary chatDoes not use existing memories or create new ones.
Project-only memoryA project setting that keeps a project's context separate from your global memory.

How it works

You chat→ChatGPT saves or recalls→Settings > Personalization > Memory→Delete or turn off→Temporary chat for private topics

1. Turn memory on or off

  1. Open Settings › Personalization and find Memory.
  2. Switch Reference saved memories on or off.
  3. Switch Reference chat history on or off. Turning it off schedules what was remembered from past chats for deletion within 30 days; the chats themselves stay unless you delete them.
  4. Select Manage memories to see, delete one, or delete all saved memories.
Careful. Deleting a chat does not delete a saved memory that came from it. To remove something completely, delete the saved memory in settings and the chat where you shared it.

2. Use memory on purpose

  • Tell it: "Remember that I am preparing for data PM roles and I prefer examples from Indian fintech."
  • Ask: "What do you remember about me?" and correct anything wrong: "Forget my old company name."
  • Keep memory for stable facts (role, goals, preferences), not one-time details.

3. Private conversations

  • Use a temporary chat for anything you do not want remembered or kept in history.
  • Use a project with project-only memory for a client or confidential work.
  • Never share passwords, card numbers, Aadhaar or PAN numbers, or customer data in any chat.
  • Check Settings › Data controls for whether your chats help improve OpenAI's models, and turn that off if you prefer.

4. ChatGPT memory compared with Claude memory

ChatGPTClaude
What is storedSaved memories plus reference to chat historyIndividual topics saved during chats; chat search on paid plans
Where to manageSettings, Personalization, Memory, Manage memoriesSettings, Your Claude, Your memory, Manage
Private chatTemporary chatIncognito chat (ghost icon)
Per-project separationProject-only memoryProject memory; turn off Use account memory

Memory does not move between the two. If you switch, ask the old assistant to list what it remembers and paste the useful parts into the new one's instructions or memory.

Common mistakes and fixes

MistakeFix
Assuming deleting a chat removes the memoryDelete the saved memory in Manage memories as well.
Never reviewing memoriesOpen Manage memories monthly and remove outdated facts.
Discussing sensitive personal topics with memory onUse a temporary chat.

Practice

  1. Open Manage memories and delete one outdated memory.
  2. Ask ChatGPT what it remembers about you, then correct one fact.
  3. Start a temporary chat, share a test fact, and check that it is not remembered later.

Quick check

Name the two memory settings.

Reference saved memories and reference chat history.

Does a temporary chat use your memories?

No. It does not use existing memories or create new ones.

What happens when you turn off reference chat history?

What was remembered from past chats is scheduled for deletion within 30 days; your chats remain unless you delete them.

Lesson 4

Connect ChatGPT to other tools: plugins, apps and custom MCP servers

The 2023 plugins, connectors, apps and the new Plugin directory explained in order; how to install a plugin and connect its app; using it in a chat; adding a custom MCP server; and staying safe.

Checked against official sources in November 2026. Lessons build on each other.
In plain words. Since July 2026 a ChatGPT plugin is a box. Inside the box there can be apps (live connections to services like Google Drive or Notion, where you sign in) and skills (written know-how that needs no account). You install the box once, then connect the apps inside it.

Key ideas

Plugin (2026)A package in the Plugin directory that can contain apps, skills and app templates. Not the same as the 2023 plugins, which were discontinued.
AppAn integration with an outside service inside ChatGPT. Many need you to sign in (OAuth). Formerly called connectors.
SkillWritten instructions and resources ChatGPT follows for a task; some plugins contain only skills.
MCP serverA service that speaks the Model Context Protocol. You can add a custom one to connect your own tools.
Developer modeSettings for building and testing your own apps; custom MCP servers can now be added from Plugins directly.
Apps SDKOpenAI's kit for developers to build apps that show interactive content in ChatGPT.

How it works

Settings > Plugins→Pick a plugin→Install plugin→Connect its app (sign in)→Use it in a chat→Review actions

1. How the names changed

WhenWhat happened
2023The first ChatGPT plugins launched. OpenAI later discontinued them in favour of GPTs.
Nov 2023GPTs: custom versions of ChatGPT with instructions, knowledge files and actions.
2025Connectors let ChatGPT search and act in apps such as Google Drive, Gmail, GitHub and SharePoint, and developers could add MCP servers.
Dec 2025Connectors were renamed apps, with an app directory and the Apps SDK.
9 Jul 2026The app directory moved into the Plugin directory. Plugins became the main way to find workflow capabilities across ChatGPT and Codex. Existing app connections were not affected.
11 Dec 2026Scheduled retirement of custom GPTs; OpenAI's replacement is plugins (Lesson 5).

2. Install a plugin and connect its app

  1. Open Settings › Plugins (or Plugins in the sidebar).
  2. Search or browse, then select the app you need or the plugin that includes it.
  3. Select Install plugin if shown.
  4. If prompted, select Connect and sign in to the service, then review and approve the access it asks for. Some apps need no separate sign-in.
  5. Plugins that contain only skills work straight away; others will not work until their required app is connected and authenticated.
Good to know. Whether you can install or use a plugin depends on your plan, workspace settings, role, region, device and the apps inside it. On Business and Enterprise, admins manage plugin installation in workspace settings and can disable apps.

3. Use a plugin in a chat

  • Ask normally and ChatGPT can choose a connected app when it helps: "Find the latest pricing deck in my Google Drive and summarise the changes."
  • Or pick it yourself from the tools (+) menu in the message box, or mention it by name in your prompt.
  • Some apps show interactive content inside the chat (maps, product lists, forms).
  • Before an app sends, deletes, books or buys something, check the action ChatGPT proposes and confirm only what you intended.

4. Connect your own tool with a custom MCP server

  1. In Settings › Plugins, choose to add a custom MCP server (you no longer need to turn on Developer mode first).
  2. Enter the server's URL and its sign-in details as the provider documents them.
  3. Read and acknowledge the risk warning shown for each server.
  4. Test it in a new chat with a read-only request before you allow any actions.

On workspace plans, custom apps may need admin approval. Only add servers you or your company run, or ones from providers you trust.

5. Safety checklist

  • Connect with the least access you need; start with read-only use.
  • Watch for instructions hidden in emails, documents or web pages (prompt injection). Review every action before confirming.
  • Remove plugins and disconnect apps you no longer use.
  • Keep customer and personal data out of apps your company has not approved.

Common mistakes and fixes

MistakeFix
Following an old guide that says "enable plugins in Beta features"Those 2023 plugins are gone; use Settings, Plugins.
Installing a plugin and expecting it to work without signing inConnect the app inside the plugin first.
Adding an unknown MCP serverOnly use servers you or trusted providers run, and read the warning.

Practice

  1. Install one plugin that includes Google Drive or OneDrive and ask for a summary of a recent document.
  2. Find one plugin that contains only skills and try it.
  3. List the apps you have connected and disconnect any you do not use.

Quick check

What can a 2026 plugin contain?

Apps, skills and app templates.

What were apps called before December 2025?

Connectors.

Do you still need Developer mode to add a custom MCP server?

No; you can add one from Plugins directly, after acknowledging a risk warning.

Did existing app connections break when the Plugin directory launched?

No. OpenAI says existing app connections were unaffected.

Lesson 5

Custom GPTs, their retirement, and skills: what to build in 2026

What custom GPTs are, the December 2026 retirement and how to migrate, skills in ChatGPT and Codex (the same SKILL.md format Claude uses), and how to choose between a project, a skill and a plugin.

Checked against official sources in November 2026. Lessons build on each other.
In plain words. A custom GPT was a ChatGPT with its own job description and reference files. OpenAI is replacing GPTs with plugins and skills, which are more portable: a skill written as a SKILL.md file can work in ChatGPT, Codex, Claude and other tools that follow the same open format.

Key ideas

Custom GPTA configured ChatGPT with instructions, knowledge files, capabilities and optional actions (API calls).
GPT retirementOpenAI's help centre lists 11 December 2026 as the scheduled date custom GPTs stop running, on all plans.
MigrationMoving a GPT to a plugin. Custom actions do not transfer; rebuild them with a supported app or a custom MCP server.
SkillA folder with SKILL.md (name, description, instructions) and optional references and scripts.
Agent Skills standardThe open SKILL.md format (agentskills.io) shared by Codex, Claude and many other tools.

How it works

List your GPTs→Export instructions + files→Rebuild as plugin / skill / project→Rebuild actions as app or MCP→Test, then share

1. The GPT retirement timeline

DateWhat OpenAI's help centre says
26 Oct 2026New GPT creation ended for affected Enterprise workspaces (FedRAMP workspaces excluded).
Until retirementExisting GPTs that are not migrated stay usable and editable. After you migrate one, the original becomes read-only.
11 Dec 2026Scheduled retirement: custom GPTs stop running. Migrated GPT links are planned to redirect to the replacement for people who have access.
Careful. Dates can move. Check OpenAI's "Custom GPT retirement and migration FAQ" before you plan around them, and migrate the GPTs you depend on now rather than in December.

2. Migrate a GPT step by step

  1. Open each GPT you own in the editor and copy its instructions, conversation starters and the list of knowledge files. Download the files if you do not have copies.
  2. Decide the replacement: a Project (personal use with files), a skill (a repeatable procedure), or a plugin (share skills plus apps with others).
  3. Use OpenAI's migration workflow where it is offered for your GPT.
  4. Rebuild any custom actions (API calls). They do not transfer: use a supported app or a custom MCP server instead.
  5. Test the replacement with the same five questions you used to test the GPT, then share the new link with users.

3. Skills in ChatGPT and Codex

Skills work inside ChatGPT and Codex. Find them under Plugins in the sidebar on the Skills tab. A skill uses the same open format as Claude skills:

release-notes/SKILL.md
---
name: release-notes
description: Turn merged pull requests into customer-friendly release notes. Use when the user asks for release notes, a changelog or "what's new".
---

# Release notes
1. Group changes into New, Improved and Fixed.
2. One line each, in plain words, starting with a verb.
3. Skip internal refactors and dependency bumps.
4. End with "Thanks to" and the contributors' names.
  • In Codex, repository skills go in .agents/skills/<name>/SKILL.md and personal skills in ~/.agents/skills/ (older guides mention ~/.codex/skills, now legacy).
  • Codex loads only each skill's name and description at start, and reads the body when it decides to use the skill, the same idea as Claude.
  • OpenAI publishes a skill-creator skill (github.com/openai/skills) that drafts the folder and SKILL.md for you.
  • Because the format is shared, the skill from the Claude guide (Lesson 5) can be reused here with little or no change.

4. Project, skill, plugin or app?

NeedChoose
Personal workspace with files and rules for one goalProject
A procedure done the same way every time (format, checklist, steps)Skill
Live data or actions in another serviceApp (or a custom MCP server)
Share skills and apps with a team as one installPlugin
An old custom GPTMigrate to one of the above before 11 Dec 2026

Common mistakes and fixes

MistakeFix
Waiting until December to migrate important GPTsCopy instructions and files now and test the replacement early.
Expecting GPT actions to move automaticallyRebuild them as an app connection or custom MCP server.
Writing a skill description that does not match how people askInclude the phrases users actually type.

Practice

  1. List every GPT you use, and choose its replacement (project, skill, app or plugin).
  2. Write a SKILL.md for one weekly task and test it in ChatGPT or Codex.
  3. Reuse the same skill in Claude and compare results.

Quick check

When are custom GPTs scheduled to stop running?

11 December 2026, according to OpenAI's help centre (check the FAQ for changes).

Do GPT custom actions transfer when you migrate?

No. Rebuild them with a supported app or a custom MCP server.

Where do repository skills live for Codex?

.agents/skills//SKILL.md

Why can the same SKILL.md work in Claude and Codex?

Both follow the open Agent Skills format (agentskills.io).

Lesson 6

ChatGPT agent, deep research, Codex and scheduled tasks

Hand ChatGPT multi-step work: agent mode on websites, deep research reports, Codex for code with AGENTS.md, scheduled tasks, and the safety habits that keep you in control.

Checked against official sources in November 2026. Lessons build on each other.
In plain words. Agent mode is like giving an intern a laptop and a clear task. It opens websites, clicks, reads and fills forms, and checks with you before anything important. Codex is the same idea for software: it works in a copy of your code and proposes changes you review.

Key ideas

Agent modeChatGPT uses its own browser and tools to complete a multi-step task, and asks before consequential actions.
Deep researchMulti-step research that reads many sources and writes a cited report.
CodexOpenAI's coding agent in the cloud, the CLI, IDEs and the desktop app.
AGENTS.mdA file in a repository that tells coding agents how to build, test and follow your conventions.
Scheduled tasksAsk ChatGPT to run something later or on a schedule, such as a daily summary.

How it works

Clear goal + limits→Agent plans steps→Works in browser / code→Asks before key actions→You review result

1. Give agent mode a good task

Agent prompt with limits
Goal: Compare 3 online SQL courses for a beginner data analyst in India.
Check: price in INR, hours, certificate, last updated date, reviews.
Output: a table plus a 3-line recommendation.
Limits: do not sign up, pay or enter any personal details. Stop and ask if a site needs login.
  • Be specific about what done looks like and what it must not do.
  • Watch the live steps; you can take over the browser or stop at any time.
  • Confirm purchases, sends and form submissions yourself.

2. Deep research that you can trust

  • Ask a focused question with a scope: market, country, time period, and the decision you need to make.
  • Ask for a sources table with dates, and open the key ones.
  • Follow up: "Which claims rely on a single source?"

3. Codex for code

  1. Open Codex in the desktop app, the web, your IDE or the CLI and connect your GitHub repository.
  2. Add an AGENTS.md at the repository root with build, test and style rules (Codex reads it; Claude Code can too).
  3. Give one clear task, such as "Add input validation to the signup form and a test for it."
  4. Review the diff, run the tests yourself, and open a pull request only when you are satisfied.
Example AGENTS.md
# AGENTS.md
## Setup
npm install
## Test before every change
npm test
## Style
- TypeScript strict mode. No new dependencies without asking.
- Small pull requests: one change per PR, with a clear title.

4. Scheduled tasks

Ask: "Every weekday at 8 am, give me three AI product news items with links" or "Remind me on Friday to send my weekly report." Manage or pause them from the schedule or tasks area in the app. Keep scheduled tasks small and check the first few results.

Many teams use both. Write skills in the shared SKILL.md format and keep project rules in AGENTS.md (imported from CLAUDE.md) so the same knowledge works in either tool.

Common mistakes and fixes

Practice

  2. Write an AGENTS.md for a small project and ask Codex (or Claude Code) for one change.
  3. Create one scheduled task and review its first three runs.

Quick check

What should every agent prompt include besides the goal?

What done looks like (output format) and the limits: what it must not do.

Which file tells Codex how to build and test your project?

AGENTS.md at the repository root.

What is the Claude equivalent of ChatGPT agent mode?
