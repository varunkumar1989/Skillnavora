23.6 Communities

  • Anthropic / Claude: the official Claude Discord and r/ClaudeAI for tips and help.
  • n8n: the n8n community forum (very active, with shared workflows) and r/n8n.
  • Lovable and Replit: official Discord servers with build challenges.

23.7 A 12-week plan with one assignment a week

23.8 Portfolio projects that impress

  1. AI front desk for a small business (capstone): WhatsApp bot + voice agent + booking app + automation.
  2. Inbox triage agent for a team: n8n + Claude + Slack, with measured time saved.
  3. PRD-to-prototype in a day: Notion PRD → Figma → Lovable or Claude Code → usability test.
  4. Feedback intelligence dashboard: Replit or Lovable app that tags feedback with AI and charts themes.
  5. Your own MCP tool that Claude uses at work (for example "create a Jira ticket from this chat").

For each, include the problem, users, metrics, architecture picture, costs, risks and guardrails, and what you'd do with an engineering team.

23.9 Best practices for learning tools that change monthly

  • Learn concepts, not buttons: triggers, tools, memory, evaluation, permissions. Buttons move; concepts last.
  • Read release notes of your main tools monthly.
  • Keep a build log: a Notion page listing what you built, prompts that worked, and mistakes.
  • Teach it: a 5-minute Loom or LinkedIn post locks in what you learned.
  • Respect costs and privacy from day one: spend limits, test data, approved tools only for work data.

23.10 Key takeaways

  • Start with free official courses (Claude Academy, DeepLearning.AI, tool academies), then build.
  • Pay for a course only for structure, feedback or community, and check how recent it is.
  • Follow a weekly assignment rhythm and publish what you build.
  • Combine official docs for facts with creators for walkthroughs and ideas.
