Known weaknesses in S1 to correct (not reproduce)

Already flagged inside S1 itself — kept as "Source-flagged misconceptions": RICE (reach − impact ≠ churn; effort is the denominator); Ansoff quadrant labels; "all AI needs RAG/vector DB"; LoRA is a technique not a model; retrieval ≠ fine-tuning; vector DBs are not 3-D file stores; CORS ≠ all UI–API traffic; white-labeling ≠ dropshipping; sprint ≠ always two weeks; MVP ≠ prototype ≠ public launch; unicorn = $1B valuation, not revenue.

Additional observations made while reading S1: - Dated product claims (pricing, plans, features of Figma Make, Lovable, Replit, n8n, Claude, ChatGPT, Gemini) go stale quickly → the handbook states capabilities generically and links to current official docs. - S1 contains no worked statistics (p-values, CIs, power). M7 adds these with computed examples. - S1 contains no SQL beyond SELECT … WHERE. M7/M9 add GROUP BY, JOIN, window functions on a provided sample dataset.
