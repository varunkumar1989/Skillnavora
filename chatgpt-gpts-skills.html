Lesson 5

Custom GPTs, their retirement, and skills: what to build in 2026

What custom GPTs are, the December 2026 retirement and how to migrate, skills in ChatGPT and Codex (the same SKILL.md format Claude uses), and how to choose between a project, a skill and a plugin.

Checked against official sources in November 2026. Lessons build on each other.
In plain words. A custom GPT was a ChatGPT with its own job description and reference files. OpenAI is replacing GPTs with plugins and skills, which are more portable: a skill written as a SKILL.md file can work in ChatGPT, Codex, Claude and other tools that follow the same open format.

Key ideas

Custom GPTA configured ChatGPT with instructions, knowledge files, capabilities and optional actions (API calls).
GPT retirementOpenAI's help centre lists 11 December 2026 as the scheduled date custom GPTs stop running, on all plans.
MigrationMoving a GPT to a plugin. Custom actions do not transfer; rebuild them with a supported app or a custom MCP server.
SkillA folder with SKILL.md (name, description, instructions) and optional references and scripts.
Agent Skills standardThe open SKILL.md format (agentskills.io) shared by Codex, Claude and many other tools.

How it works

List your GPTs→Export instructions + files→Rebuild as plugin / skill / project→Rebuild actions as app or MCP→Test, then share

1. The GPT retirement timeline

DateWhat OpenAI's help centre says
26 Oct 2026New GPT creation ended for affected Enterprise workspaces (FedRAMP workspaces excluded).
Until retirementExisting GPTs that are not migrated stay usable and editable. After you migrate one, the original becomes read-only.
11 Dec 2026Scheduled retirement: custom GPTs stop running. Migrated GPT links are planned to redirect to the replacement for people who have access.
Careful. Dates can move. Check OpenAI's "Custom GPT retirement and migration FAQ" before you plan around them, and migrate the GPTs you depend on now rather than in December.

2. Migrate a GPT step by step

  1. Open each GPT you own in the editor and copy its instructions, conversation starters and the list of knowledge files. Download the files if you do not have copies.
  2. Decide the replacement: a Project (personal use with files), a skill (a repeatable procedure), or a plugin (share skills plus apps with others).
  3. Use OpenAI's migration workflow where it is offered for your GPT.
  4. Rebuild any custom actions (API calls). They do not transfer: use a supported app or a custom MCP server instead.
  5. Test the replacement with the same five questions you used to test the GPT, then share the new link with users.

3. Skills in ChatGPT and Codex

Skills work inside ChatGPT and Codex. Find them under Plugins in the sidebar on the Skills tab. A skill uses the same open format as Claude skills:

release-notes/SKILL.md
---
name: release-notes
description: Turn merged pull requests into customer-friendly release notes. Use when the user asks for release notes, a changelog or "what's new".
---

# Release notes
1. Group changes into New, Improved and Fixed.
2. One line each, in plain words, starting with a verb.
3. Skip internal refactors and dependency bumps.
4. End with "Thanks to" and the contributors' names.
  • In Codex, repository skills go in .agents/skills/<name>/SKILL.md and personal skills in ~/.agents/skills/ (older guides mention ~/.codex/skills, now legacy).
  • Codex loads only each skill's name and description at start, and reads the body when it decides to use the skill, the same idea as Claude.
  • OpenAI publishes a skill-creator skill (github.com/openai/skills) that drafts the folder and SKILL.md for you.
  • Because the format is shared, the skill from the Claude guide (Lesson 5) can be reused here with little or no change.

4. Project, skill, plugin or app?

NeedChoose
Personal workspace with files and rules for one goalProject
A procedure done the same way every time (format, checklist, steps)Skill
Live data or actions in another serviceApp (or a custom MCP server)
Share skills and apps with a team as one installPlugin
An old custom GPTMigrate to one of the above before 11 Dec 2026

Common mistakes and fixes

MistakeFix
Waiting until December to migrate important GPTsCopy instructions and files now and test the replacement early.
Expecting GPT actions to move automaticallyRebuild them as an app connection or custom MCP server.
Writing a skill description that does not match how people askInclude the phrases users actually type.

Practice

  1. List every GPT you use, and choose its replacement (project, skill, app or plugin).
  2. Write a SKILL.md for one weekly task and test it in ChatGPT or Codex.
  3. Reuse the same skill in Claude and compare results.

Quick check

When are custom GPTs scheduled to stop running?

11 December 2026, according to OpenAI's help centre (check the FAQ for changes).

Do GPT custom actions transfer when you migrate?

No. Rebuild them with a supported app or a custom MCP server.

Where do repository skills live for Codex?

.agents/skills//SKILL.md

Why can the same SKILL.md work in Claude and Codex?

Both follow the open Agent Skills format (agentskills.io).
