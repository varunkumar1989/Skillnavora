1. Data Analytics and AI Tools

Lesson 1.1

AI-powered analytics with Microsoft Copilot

  • Copilot in Excel. Ask questions in natural language to summarise data, suggest charts and spot trends; availability depends on your Microsoft plan.
  • Prompt used. 'Summarize quarterly growth trends and highlight the top 5 outlier product categories by margin percentage.'
  • Verify. Check any AI result against the data; the code below shows how to find outliers yourself with the IQR rule.

Read this lesson with its practice task (PDF) · in the full lesson guide, page 69

Read more (official sites): Copilot in Excel ↗

2. Data Scientist

Lesson 2.1

EDA with Python, feature engineering and predictive models

  • EDA. Look at shape, types, missing values, distributions and relationships using Pandas, Matplotlib and Seaborn.
  • Feature engineering. Create useful inputs such as margin percentage or days since last purchase.
  • Predictive models. Train on a split and measure on unseen data; see the machine learning lesson in Department 2.

Read this lesson with its practice task (PDF) · in the full lesson guide, page 70

Read more (official sites): Seaborn ↗ · Matplotlib ↗

3. Data Engineer

Lesson 3.1

ETL pipelines, data warehousing and indexing

  • ETL. Extract the raw data, transform it (clean, dedupe, type), load it into a table.
  • Warehouses. BigQuery and Snowflake store large data for analysis; they separate storage from compute and charge differently, so check current pricing.
  • Indexing. An index speeds lookups on a column but slows writes slightly.

Read this lesson with its practice task (PDF) · in the full lesson guide, page 71

Read more (official sites): BigQuery ↗ · Snowflake ↗

4. Power BI Specialist

Lesson 4.1

Data modelling, star schemas, DAX and publishing

  • Star schema. A central fact table (sales) linked to dimension tables (date, product, customer).
  • DAX. CALCULATE changes the filter context of a measure.
  • Publishing. Publish to the Power BI Service, set refresh and share by workspace with correct access.

Read this lesson with its practice task (PDF) · in the full lesson guide, page 72
